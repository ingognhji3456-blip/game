## 0. 한 줄 소개

**여섯 원소의 탑을 서로 이웃하게 세워 "공명"을 일으키고, 영웅과 함께 잿빛 안개로부터 마을의 등불을 지키는 판타지 타워 디펜스.**

- 장르: 타워 디펜스 (고정 길 + 길 만들기 혼합)
- 한 판: 8~15분 · 캠페인 30판 (지역 5곳 × 6판)
- 플랫폼: 브라우저 (데스크톱·휴대폰), 설치·인터넷 불필요, 파일 하나로 실행
- 언어: 한국어

## 1. 디자인 기둥

모든 결정은 아래 네 기둥 중 하나 이상을 강화해야 합니다. 어느 것도 강화하지 않는 기능은 넣지 않습니다.

1. **배치가 곧 퍼즐이다.** 어떤 탑을 고르느냐만큼 *어디에, 무엇 옆에* 놓느냐가 중요합니다. 공명(§6)은 이 기둥의 핵심이고, 이 게임을 다른 타워 디펜스와 구별하는 특징입니다.
2. **모든 위협은 읽을 수 있다.** 적의 특성·저항·다음 행동은 화면에서 확인할 수 있어야 하고, 플레이어가 알 수 없는 이유로 지는 일은 없어야 합니다. 새 적은 반드시 "혼자, 안전하게" 먼저 등장합니다. 보스가 탑을 멈추게 할 때는 미리 경고합니다.
3. **캐릭터가 있는 방어.** 영웅 여섯 명은 각자의 이야기, 말투, 전투 방식이 있습니다. 탑과 적도 "누가 왜 만들었는가"가 보이게 디자인합니다.
4. **짧고 밀도 있는 판.** 한 판은 15분을 넘기지 않습니다. 기다리는 시간은 조기 호출과 배속으로 줄일 수 있어야 합니다.

## 2. 세계관 요약

자세한 내용은 [story.md](design/story.md).

- **울림의 땅**: 모든 생명과 사물은 고유한 "울림(원소)"을 가집니다. 세상의 중심에는 이 울림을 조율하는 **대종(大鐘)** 이 있었습니다.
- 어느 날 대종에 금이 가고, 그 틈에서 **잿빛 안개**가 흘러나오기 시작했습니다. 안개는 울림을 지워 버립니다. 안개에 삼켜진 동물과 사물은 속이 텅 빈 **잿빛 것들**이 되어, 마을마다 지키는 **울림등**(등불)을 향해 몰려옵니다.
- 울림등의 불꽃이 모두 꺼지면 마을은 안개에 잠깁니다. 플레이어는 솔빛 마을의 **공명 수호대**가 되어 등불을 지키고, 대종이 있는 땅의 심장부까지 나아갑니다.
- 분위기: **따뜻하지만 위기감 있는 판타지.** 마을과 사람들은 따뜻하고, 안개는 조용하고 서늘합니다. 잔혹한 묘사는 하지 않습니다.

## 3. 핵심 루프

### 3.1 한 판 안에서

```
준비(건설) → 웨이브 호출 → 전투(배치·강화·영웅 조작) → 다음 웨이브 … → 마지막 웨이브 처치 → 결과
```

1. 판이 시작되면 시간이 멈춘 **준비 단계**입니다. 시작 골드로 탑을 짓고 영웅 위치를 정합니다.
2. 플레이어가 **웨이브 호출**을 누르면 첫 웨이브가 시작됩니다.
3. 적은 입구에서 나와 울림등을 향해 이동합니다. 등불에 닿은 적은 사라지고 **등불 불꽃**을 꺼뜨립니다.
4. 적을 처치하면 골드를 얻습니다. 골드로 탑을 더 짓거나 강화합니다.
5. 다음 웨이브는 이전 웨이브가 모두 나온 뒤 카운트다운이 끝나면 자동으로 시작합니다. 일찍 호출하면 남은 시간만큼 **보너스 골드**를 받습니다.
6. 마지막 웨이브까지 모두 처치하면 승리. 불꽃이 모두 꺼지면 패배.

### 3.2 판 밖에서

```
월드 지도 → 맵 선택(모드·영웅) → 판 → 별 획득 → 기술 나무 / 새 탑·영웅·이야기 해금 → 다음 맵
```

## 4. 맵과 길

### 4.1 격자

- 맵은 정사각형 칸으로 된 격자입니다. 크기 **16 × 9칸** (가로 × 세로)으로 통일합니다.
- 모든 거리·사거리·속도는 **칸 단위**입니다. (예: 사거리 3.0 = 3칸)

### 4.2 칸 종류

| 칸 | 기호 | 적이 걸을 수 있음 | 탑을 지을 수 있음 | 설명 |
|---|---|---|---|---|
| 길 | `.` | O | X | 고정 길. 적은 이 위로만 다닙니다. |
| 공터 | `,` | O | O | **길 만들기 칸.** 탑을 지으면 막혀서 적이 돌아갑니다. |
| 건설지 | `#` | X | O | 탑만 지을 수 있는 땅. |
| 장애물 | `~` `^` `T` `%` `=` | X | X | 물, 바위, 나무, 용암, 기둥 등. 모양만 다릅니다. |
| 입구 | `S` | O | X | 적이 나오는 곳 (지상). |
| 하늘 입구 | `A` | — | X | (2026-11-10부터 쓰지 않음 — 그림 장식) 비행 적도 지상 입구에서 나옵니다. |
| 울림등 | `L` | O | X | 지켜야 할 등불. 맵마다 하나. |

### 4.3 길 종류

- **고정 길 맵**: 공터가 없습니다. 적은 정해진 길로만 갑니다. 길이 같은 갈림길에서는 적이 고르게 나뉩니다.
- **길 만들기 맵**: 넓은 공터가 있습니다. 탑으로 미로를 만들어 적이 더 오래 걷게 할 수 있습니다.
- **혼합 맵**: 고정 길 일부와 공터 구역이 섞여 있습니다.

### 4.4 길을 완전히 막을 수 없음

공터에 탑을 지을 때, 다음 중 하나라도 해당하면 **지을 수 없고**, 이유를 화면에 보여 줍니다.
- 어떤 입구에서도 울림등까지 가는 길이 사라지는 경우 → "길을 완전히 막을 수 없습니다"
- 지금 맵 위에 있는 지상 적 중 누구라도 울림등에 갈 수 없게 되는 경우
- 그 칸 위에 지상 적이 서 있거나, 바로 들어서려는 경우

### 4.5 이동

- **지상 적**: 울림등까지의 최단 거리 지도(흐름장, 대각선 이동 포함)를 따라 이동합니다. 탑을 짓거나 팔면 즉시 다시 계산합니다.
- **비행 적**: 지상 적과 **같은 입구에서 나와 같은 길을 따라** 날아갑니다(2026-11-10 개정 — 예전엔 하늘 입구에서 곧게 날아와 잡기 어려웠음). 붙잡히지 않고, 지상 전용 탑에 맞지 않습니다.
- 적의 "진행도"는 울림등까지 길을 따라 남은 거리입니다(지상·비행 같음). 표적 "첫째"는 남은 거리가 가장 짧은 적입니다.

## 5. 탑 공통 규칙

자세한 탑별 설계는 [towers.md](design/towers.md).

- 탑은 **6원소 × 3종 = 18종**입니다.
- 한 칸에 하나. 건설지(`#`) 또는 공터(`,`)에만 짓습니다.
- **단계**: Lv1 → Lv2 → Lv3 → **분기 Lv4 (A 또는 B 중 하나)**. 분기는 서로 다른 플레이 방식을 만들어야 합니다(한쪽이 단순 상위 호환이면 안 됩니다).
  - 분기는 첫 보스(1-6)를 처치한 뒤 해금됩니다.
- **건설 시간**: 전투 중에 지은 탑은 **1초 동안 준비** 상태입니다(공격·지원·공명 없음). 첫 웨이브 전에는 즉시 완성됩니다.
- **판매**: 지금까지 쓴 골드의 70%를 돌려받습니다. **첫 웨이브 시작 전**에는 100%(실수 되돌리기). 판 칸에는 **5초 동안** 다시 지을 수 없습니다(미로를 껐다 켜는 꼼수 방지).
- **표적 우선순위** (공격 탑만): 첫째 · 마지막 · 강한 적(남은 체력 최대) · 약한 적 · 가까운 적. 기본값은 "첫째". 탑마다 바꿀 수 있습니다.
- **공격 대상**: 탑마다 지상만 / 공중만 / 둘 다 중 하나입니다. 화면의 탑 정보에 아이콘으로 표시합니다.
- **지원 탑**: 대장간·축전기·성소는 이웃 탑을 돕습니다. **수정 광산**은 골드를 만드는 경제 탑입니다.
- 탑은 자기 원소에 **면역이거나 흡수하는 적을 표적으로 삼지 않습니다**(헛수고·회복시키기 방지).

## 6. 원소와 공명

### 6.1 여섯 원소

색과 **모양**을 함께 써서 색을 구별하기 어려운 사람도 알아볼 수 있게 합니다.

| 원소 | id | 색 | 모양 | 성격 |
|---|---|---|---|---|
| 불 | `fire` | 주황 `#ff6b3d` | 불꽃 | 높은 화력, 화상, 폭발 |
| 얼음 | `frost` | 하늘 `#5fd4ff` | 육각 결정 | 감속, 빙결, 관통 |
| 폭풍 | `storm` | 보라 `#9b8cff` | 번개 | 연쇄, 속도, 밀쳐내기 |
| 대지 | `earth` | 이끼 `#8fcf5a` | 산 | 붙잡기, 갑옷 파쇄, 경제 |
| 빛 | `light` | 금 `#ffe48a` | 별 | 집중, 탐지, 회복 |
| 어둠 | `dark` | 자홍 `#d14fc0` | 초승달 | 저주, 속박, 처형 |

### 6.2 공명 규칙

1. 탑이 **이웃한 8칸**(대각선 포함) 안에 다른 탑이 있으면 둘 사이에 **공명 연결**이 생깁니다.
2. 연결된 두 탑의 원소 조합에 따라 **공명 효과**가 정해지고, **두 탑 모두** 그 효과를 받습니다.
3. 한 탑은 여러 연결을 가질 수 있지만, **같은 효과는 한 번만** 적용됩니다. (불 탑 옆에 얼음 탑이 둘이어도 "증기 폭발"은 한 번)
   → 같은 원소를 몰아 짓기보다 **여러 원소를 섞을수록** 강해집니다.
4. **지원 탑**(대장간·축전기·성소)은 이웃에게 공명 효과를 주지만, 자신은 공격 효과 대신 **공명 증폭**을 받습니다: 서로 다른 효과 하나당 지원 효과 +10%.
5. **수정 광산은 공명하지 않습니다.** 연결을 만들지도 받지도 않습니다(경제 탑이 공짜 공명 짝이 되는 것을 막음).
6. 탑에 적용되지 않는 효과(예: 바위 병영의 "사거리 +15%")는 화면에 흐리게 표시하고 아무 일도 하지 않습니다.
7. 탑을 지을 때 **미리보기**로 생길 연결과 효과를 보여 줍니다.
8. **멈춘 탑**(§7.2.5)과 **공명이 끊긴 탑**은 그동안 연결이 사라집니다. 그 탑과 이어졌던 이웃도 그 연결의 효과를 잃습니다.

### 6.3 공명 효과 (16가지)

| 조합 | 이름 | id | 효과 |
|---|---|---|---|
| 같은 원소 | 순수 공명 | `pure` | 피해 +12% |
| 불 + 얼음 | 증기 폭발 | `steam` | 명중 시 25% 확률로 작은 폭발(반경 0.8칸, 피해의 40%) |
| 불 + 폭풍 | 과열 | `overheat` | 피해 +20% |
| 불 + 대지 | 용암 | `magma` | 명중 시 갑옷 −5%p (최대 −20%p, 4초) |
| 불 + 빛 | 태양 불꽃 | `sunfire` | 사거리 +15% |
| 불 + 어둠 | 잿불 | `cinder` | 명중 시 화상(피해의 30%를 3초에 걸쳐) |
| 얼음 + 폭풍 | 초전도 | `superconduct` | 빙결·기절·속박된 적에게 피해 +50% |
| 얼음 + 대지 | 영구 동토 | `permafrost` | 명중 시 감속 15% (1초) |
| 얼음 + 빛 | 굴절 | `refraction` | 비행 적에게 피해 +30% |
| 얼음 + 어둠 | 고요한 밤 | `stillness` | 명중한 적의 재생·치유 −50% (3초), 보호막에 주는 피해 +50% |
| 폭풍 + 대지 | 접지 | `grounding` | 명중 시 10% 확률로 기절 0.5초 (보스 제외) |
| 폭풍 + 빛 | 뇌광 | `flash` | 공격 속도 +20% |
| 폭풍 + 어둠 | 폭풍우 | `tempest` | 명중 시 근처(1.5칸) 적 1명에게 튐 (피해의 35%) |
| 대지 + 빛 | 축복받은 땅 | `blessed` | 이 탑이 처치한 적의 현상금 +50% |
| 대지 + 어둠 | 중력 | `gravity` | 지상 적에게 피해 +15%, 명중 시 감속 10% (1초) |
| 빛 + 어둠 | 황혼 | `twilight` | 갑옷 25% 무시, 정예·보스에게 피해 +15% |

설계 의도:
- 수치형(과열·뇌광·순수)은 언제나 쓸모 있는 "무난한 짝", 조건형(초전도·굴절·중력·황혼)은 상황을 읽으면 더 강한 "전문 짝"입니다.
- 모든 원소가 다른 다섯 원소 각각과 의미 있는 짝을 이룹니다. 특정 원소가 "공명 쓰레기"가 되지 않도록 시뮬레이션으로 확인합니다.

## 7. 피해 계산 규칙

모든 피해는 아래 순서로 계산합니다. **같은 단계 안의 보너스는 더하고, 단계끼리는 곱합니다.**

```
최종 피해 = 기본 피해
          × (1 + 공격 쪽 피해 보너스 합)        ← 대장간, 과열, 순수 공명, 조건부(초전도·굴절·중력·황혼), 기술 나무
          × (1 + 맞는 쪽 받는 피해 증가 합)      ← 저주, 서리 장막
          × (1 − 유효 갑옷)                     ← 유효 갑옷 = max(0, 갑옷 − 파쇄) × (1 − 갑옷 무시)
          × 원소 친화 배율                       ← 약점 ×1.5 · 보통 ×1 · 저항 ×0.5 · 면역 ×0 · 흡수(회복)
          × 치명타 배율(치명타일 때 ×2)
```

- 결과는 소수점까지 유지하고, 화면에는 반올림해 보여 줍니다.
- **보호막**은 체력보다 먼저 깎입니다. 보호막에 대한 추가 피해(고요한 밤, 얼음 송곳탑)는 보호막에만 적용됩니다.
- **흡수**: 그 원소 피해만큼 체력을 회복합니다(최대 체력 초과 불가).
- 지속 피해(화상·출혈·장판)는 갑옷을 **무시**하고 원소 친화는 적용합니다.

### 7.1 상태 이상 (적에게 걸리는 것)

| 상태 | 효과 | 중첩 규칙 | 보스 |
|---|---|---|---|
| 감속 | 이동 속도 −N% | 가장 강한 것 하나만 | 효과 50% |
| 빙결 | 이동·공격 정지 | 강한 제어(§7.2.6) | 시간 30% |
| 기절 | 이동·공격 정지 | 강한 제어 | 면역 |
| 속박 | 이동 정지 (공격은 가능) | 강한 제어 | 시간 20% |
| 공중 띄움 | 이동·공격 정지, 붙잡힘 해제 | 강한 제어 | 면역 |
| 화상 | 초당 지속 피해 (출처 탑의 원소) | 출처마다 따로, 같은 출처는 갱신 | 적용 |
| 출혈 | 초당 지속 피해 (어둠) | 출처마다 따로 | 적용 |
| 저주 | 받는 피해 +N% | 가장 강한 것 하나만 | 적용 |
| 서리 장막 | 감속된 동안 받는 피해 +N% | 가장 강한 것 하나만 | 적용 |
| 갑옷 파쇄 | 갑옷 −N%p | 출처 종류별 상한까지 누적 | 적용 |
| 치유 감소 | 재생·치유 −50% | 갱신 | 적용 |
| 정화 | 보호막 제거, 재생·치유·보호막 재생 정지 | 갱신 | 적용 |
| 실명 | 원거리 공격 불가, 은신 드러남 | 갱신 | 적용 |

### 7.2 엔진 규칙 부록

구현할 때 추측하지 않도록 정해 둔 규칙입니다.

1. **명중(hit)이란**: "명중 시" 효과(확률 효과, 상태 부여, 공명의 명중 효과)는 다음에서만 발생합니다.
   - 투사체·관통·주변 파동·덫·병사·영웅의 공격이 적 하나에 맞을 때마다 1번.
   - 연쇄 번개: 첫 대상은 1번, 튄 대상은 **확률 효과 절반**.
   - 지속 광선(햇살 렌즈): 같은 대상에게 **0.5초마다** 1번.
   - **발생하지 않음**: 지속 피해(화상·출혈), 장판, 증기 폭발·폭풍우 튐·방전 같은 **부가 피해**. (부가 피해는 다른 부가 피해를 일으키지 않습니다.)
2. **부가 효과의 원소**: 공명·지원으로 덧붙는 피해와 화상은 **그것을 받은 탑의 원소**입니다. (어둠 탑의 잿불 화상 = 어둠 피해)
3. **원소 친화는 피해에만** 적용됩니다. 감속·빙결 같은 상태 이상은 친화와 무관하고, 보스 규칙(§7.1 표)만 따릅니다.
4. **은신·굴착**
   - 은신 적은 탐지 범위 밖에서 **표적이 될 수 없지만**, 표적 없이 퍼지는 피해(폭발 범위, 주변 파동, 관통, 장판, 덫)에는 맞습니다. 연쇄는 표적이 필요하므로 드러난 적에게만 튑니다.
   - 붙잡은 병사·영웅은 은신 적을 공격할 수 있습니다.
   - 굴착 중인 적은 **모든 피해와 효과를 받지 않고** 붙잡히지 않습니다. 땅에서 나오는 순간 그 칸의 덫에는 걸립니다.
5. **멈춘 탑과 끊긴 공명**: 탑의 상태는 둘뿐입니다.
   - **멈춤**(흰뿔의 서리 숨결, 고래의 벼락, 해파리의 마비 폭발, 침묵): 공격·지원 효과·공명 연결이 모두 꺼집니다. 이미 깔린 장판·덫·병사는 그대로이고, 수정 광산 수입은 계속됩니다.
   - **공명 끊김**(공명 차단): 공명 연결만 꺼집니다.
   - 보스가 탑을 멈추게 할 때는 **1.5초 전에 대상 탑 위에 경고 표시**를 띄웁니다.
6. **강한 제어 감쇠**: 빙결·기절·속박·공중 띄움은 하나의 "강한 제어"로 묶습니다.
   - 이미 강한 제어에 걸린 적에게는 새 강한 제어가 걸리지 않습니다(시간 연장 없음).
   - 4초 안에 다시 걸리면 지속 시간이 ×1 → ×0.5 → ×0.25로 줄고, 그다음에는 2초 동안 강한 제어에 면역입니다.
7. **밀쳐내기**: 적이 **실제로 지나온 칸 기록**을 따라 뒤로 이동시킵니다. 밀릴 때마다 그 적에게 **밀림 저항** +35%(최대 100%)가 쌓이고 초당 25%씩 줄어듭니다. 실제 밀리는 거리 = 거리 × (1 − 저항). 크기 "대" 이상과 보스는 밀리지 않습니다.
8. **지원 효과 중첩**: 같은 종류의 지원 효과(대장간 피해, 축전기 속도, 성소 사거리, 무기고 치명타 …)는 **가장 강한 하나만** 적용됩니다. 종류가 다르면 함께 적용됩니다.
9. **현상금 보너스**(축복받은 땅, 보석 세공소, 야로, 기술 나무)는 더하되 **최대 +75%** 입니다.
10. **수정 광산 수입 감소**: 광산이 여러 개면 수입이 많은 순서로 100% · 80% · 60% · 40% · 40% … 만 받습니다.
11. **재생**: 2초 동안 피해를 받지 않으면 매초 최대 체력의 N%를 회복합니다(지속 피해도 "피해"입니다).
12. **보호막 재생**: 보호막은 정해진 시간 동안 피해를 받지 않으면 다시 차오릅니다(지속 피해도 막습니다).
13. **적응**: 직접 명중(1번 규칙의 "명중")만 셉니다. 같은 원소로 연속 명중할 때마다 그 원소 저항이 쌓이고, 다른 원소에 명중하면 0으로 돌아갑니다.
14. **정예**: 등불 불꽃을 2개 이상 꺼뜨리는 큰 적(데이터의 `elite: true`). 화면에 정예 표시가 붙습니다.

## 8. 적 공통 규칙

자세한 적별 설계는 [enemies.md](design/enemies.md).

- 적 **40종 + 보스 6종**. 지역마다 8종의 새 적과 보스 하나(마지막 지역은 둘)가 등장합니다.
- **등불 불꽃 소모**: 일반 1, 정예 2~3, 보스는 등불에 닿으면 **즉시 패배**.
- **특성(trait)** 은 정해진 목록에서만 고릅니다. 특성마다 아이콘과 설명이 있고, 적을 누르면 볼 수 있습니다.

| 특성 | id | 설명 | 대표 대응 |
|---|---|---|---|
| 비행 | `flying` | 길을 따라 날아옴, 붙잡을 수 없음, 지상 전용 탑에 안 맞음 | 공중 공격 탑 |
| 갑옷 | `armor` | 받는 피해 N% 감소 | 갑옷 파쇄, 황혼, 한 방이 큰 탑 |
| 재생 | `regen` | 2초간 안 맞으면 초당 최대 체력의 N% 회복 | 끊김 없는 공격, 화상, 순간 화력 |
| 분열 | `split` | 죽으면 작은 적 여러 마리 | 광역 |
| 은신 | `stealth` | 탐지 범위 밖에서는 표적이 될 수 없음 | 성소, 세라, 광휘 탑, 광역, 병사 |
| 보호막 | `shield` | 체력 위에 보호막, 일정 시간 피해가 없으면 재생 | 끊김 없는 공격, 한 방, 얼음 송곳탑, 고요한 밤 |
| 치유사 | `healer` | 주기적으로 주변 적 치유 | 우선 처치, 정적의 종, 치유 감소 |
| 보호막 부여 | `shielder` | 주기적으로 주변 적에게 보호막 | 우선 처치, 정화 |
| 굴착 | `burrow` | 주기적으로 땅속에 숨음(피해·붙잡기 불가) | 넓게 분산, 덫, 장판 |

| 죽음 폭발 | `deathburst` | 죽을 때 주변 영웅·병사 피해 | 원거리 처리 |
| 원거리 | `ranged` | 걸으면서 영웅·병사를 공격 | 원거리 탑, 영웅 거리 두기, 실명 |
| 마비 폭발 | `shock` | 죽을 때 주변 탑을 잠시 멈춤 | 먼 거리에서 처치 |
| 침묵 | `silence` | 지나가는 동안 주변 탑을 멈춤 | 사거리 긴 탑, 붙잡아 한곳에 고정 |
| 적응 | `adaptive` | 같은 원소에 연속으로 맞으면 그 원소 저항이 쌓임 | 여러 원소 섞기 |
| 공명 차단 | `dampen` | 주변 탑의 공명 연결을 끊음 | 우선 처치, 기본 화력 |
| 붙잡기 불가 | `unstoppable` | 영웅·병사에게 붙잡히지 않음 | 탑 화력 |

## 9. 영웅

자세한 영웅별 설계는 [heroes.md](design/heroes.md).

- 판마다 해금된 영웅 **한 명**을 데리고 갑니다.
- **조작**: 영웅을 누른 뒤 땅을 누르면 그곳으로 걸어갑니다(키보드: `H`로 영웅 선택). 길·공터·건설지 위를 걸을 수 있고, 탑과 장애물은 피해 갑니다.
- **자동 전투**: 사거리 안의 적을 알아서 공격합니다. 근접 영웅은 지상 적을 **붙잡습니다**(붙잡기 수만큼).
- **기술**: 영웅마다 액티브 기술 하나(재사용 대기시간)와 패시브 하나. 기술 버튼을 누르고 위치·대상을 고릅니다(키보드: `Q`).
- **레벨**: 판 안에서 Lv1~5. 영웅이 처치하거나 영웅 근처(2.5칸)에서 적이 죽으면 경험치를 얻습니다. 레벨마다 체력·공격력 +12%, 기술 위력 +10%.
- **쓰러짐**: 체력이 0이 되면 15초 뒤 울림등 옆에서 다시 일어납니다.

### 9.1 붙잡기

- 붙잡기 능력이 있는 아군(영웅, 바위 병영의 병사, 바위의 벽)은 주변의 지상 적을 붙잡습니다.
- 붙잡힌 적은 멈춰서 붙잡은 아군과 싸웁니다. 아군이 쓰러지거나 떠나면 다시 걷습니다.
- 비행·굴착 중·붙잡기 불가 적은 붙잡을 수 없습니다.

## 10. 웨이브와 경제

- 맵마다 웨이브 수가 정해져 있습니다(첫 맵 6 → 마지막 맵 20).
- 웨이브는 여러 무리로 이루어집니다. 무리 = (적 종류, 수, 간격, 시작 시각, 입구).
- **다음 웨이브 카운트다운**: 이전 웨이브의 마지막 적이 나온 뒤 15초.
- **조기 호출 보너스**: 남은 초 × (다음 웨이브 기본 보너스 / 15)골드. 화면 버튼에 받을 보너스를 미리 표시합니다.
- **현상금**: 적마다 정해진 골드. 분열로 나온 작은 적은 현상금이 작습니다.
- **웨이브 시작 수입**: 수정 광산은 웨이브가 시작될 때 골드를 줍니다(§7.2.10 감소 규칙).
- **배속**: 1× · 2× · 3×. 일시정지 중에도 건설·강화·판매는 할 수 있습니다.

## 11. 별과 진행

### 11.1 등불 불꽃과 별

울림등에는 **불꽃 12개**가 있습니다.

| 조건 | 별 |
|---|---|
| 클리어 | ★1 |
| 불꽃 6개 이상 남김 | ★2 |
| 불꽃 11개 이상 남김 | ★3 |
| 그 맵의 **공명 과제** 달성(같은 판에서 클리어 포함) | ★+1 |
| 그 맵의 **도전** 클리어 | ★+1 |

맵당 최대 ★5, 전체 최대 ★150.

### 11.2 공명 과제

맵마다 공명을 활용하는 과제가 하나 있습니다. 예: "서로 다른 공명 효과 5가지를 동시에 켜기", "한 탑에 공명 효과 3개 모으기", "불·얼음·폭풍 탑을 모두 짓고 승리". 과제는 판 도중 진행 상황이 화면에 표시됩니다. 과제는 이 게임의 핵심 특징을 배우는 길잡이 역할도 합니다.

### 11.3 모드

- **캠페인**: 기본. 공명 과제는 캠페인 판에서 달성합니다.
- **도전**: 클리어 후 열림. 맵마다 특별한 규칙 하나(예: "얼음과 폭풍 탑만", "탑 8개 이하", "영웅 없이", "불꽃 1개"). 도전에서는 **기술 나무 효과가 없고**, 쓸 수 있는 탑은 *그 시점까지 해금된 전부*입니다.
- **무한**: 지역 보스를 처치하면 그 지역의 무한 맵이 열립니다. 끝없이 강해지는 웨이브를 몇 개까지 버티는지 기록합니다.

### 11.4 해금 일정

- **탑**: (2026-11-10 개정) 맵 해금이 아니라 **뽑기로만** 얻습니다 — §11.5. 아래 maps.md의 "새 탑" 맵은 이제 **새 탑 확정권**을 주는 시점입니다.
- **분기 강화(Lv4)**: 1-6 처치 후.
- **영웅**: 카라(처음), 세라(1-4), 시오(2-1), 제나(3-1), 바위(4-1), 야로(5-1).
- 새 탑이 해금되는 맵은 그 탑이 잘 통하는 지형·적 구성으로 만들어, 자연스럽게 쓰는 법을 익히게 합니다.

> "탑은 이제 뽑기로만 얻을 수 있게 하고, 기본 탑들은 주어진 상태로, 중복이 뜨면 그 탑은 업그레이드가 될 수 있게"

| 항목 | 내용 |

| 재화 | **공명석**: 처음 100, 판 결과 — 승리 15(패배 5), 맵 첫 클리어 +100, 새 별마다 +30, 무한 모드 최고 기록 웨이브마다 +4 |
| 뽑기 | 1회 100, 10회 900(희귀 이상 1개 확정). 모든 탑이 처음부터 뽑기에 들어 있음 |
| 등급 | 일반 60% (1지역 탑 6종) · 희귀 30% (2지역 + 바람 포탑 6종) · 영웅 10% (3~4지역 탑 6종) |
| 천장 | 30회 안에 영웅 등급 확정 (영웅이 나오면 다시 셈) |
| 새 탑 확정권 | 예전에 새 탑이 해금되던 맵 바로 앞 맵을 처음 클리어하면 1장(기본 탑 제외, 캠페인 전체 15장) — **아직 없는 탑만** 나옴. 그래서 탑 **수**는 예전 해금 일정보다 늦어지지 않고, **어떤 탑**인지만 뽑기로 정해짐 |
| 중복 | 그 탑 **강화 +1** (최대 +5). +5에서 또 나오면 공명석 30을 돌려받음 |
| 강화 효과 | 단계마다 +6% — 공격 탑 공격력, 지원 탑 지원 효과, 병영 병사 체력·공격력, 광산 수입 (+5 = +30%). **도전 모드에서는 쓰지 않음**(기술 나무와 같음) |
| 예전 기록 | 뽑기 전 기록은 그때까지 해금한 탑을 그대로 가짐 |

- 전투에 가져가는 탑 = 가진 탑 전부. 판을 시작할 때 강화 단계를 판 설정에 복사해 두어, 이어하기(명령 재현)가 같은 결과를 냅니다.
- 은신 적(2-5부터)은 성소가 없어도 세라(1-4 합류, 탐지)로 볼 수 있어, 뽑기 운으로 막히는 맵은 없습니다.
- 밸런스 측정 봇은 예전 해금 일정의 탑(`towersFor`)과 강화 0으로 잽니다 — 사람이 강화를 쌓으면 그만큼 쉬워집니다.

## 12. 기술 나무

별을 써서 영구 강화를 찍습니다. **언제든 무료로 초기화**할 수 있습니다. 4갈래 × 5칸 = 20칸, 모두 찍는 데 ★118. (캠페인 ★3만으로는 ★90 → 모두 찍으려면 공명 과제·도전 별이 필요합니다.)

| 갈래 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 축성 | 건설 비용 −5% (★3) | 분기 비용 −10% (★4) | 모든 탑 사거리 +5% (★6) | 강화 비용 −8% (★7) | 분기 탑 피해 +10% (★10) |
| 공명 | 순수 공명 +6%p (★3) | 공명 증폭 +5%p (★4) | 공명 효과 3개 이상인 탑 피해 +10% (★6) | 공명 효과 수치 +20% (★7) | 공명 효과 4개 이상인 탑 공격 속도 +15% (★10) |
| 영웅 | 영웅 체력 +15% (★3) | 부활 시간 −30% (★4) | 기술 재사용 −15% (★6) | 시작 레벨 2 (★7) | 영웅 피해 +20% (★9) |
| 등불 | 시작 골드 +8% (★3) | 조기 호출 보너스 +50% (★4) | 수정 광산 수입 +20% (★6) | 현상금 +8% (★7) | 등불 보호막: 처음 새어 든 일반 적 2마리는 불꽃을 꺼뜨리지 않음 (★9) |

- 각 갈래는 앞 칸을 찍어야 다음 칸을 찍을 수 있습니다.
- "공명 효과 수치 +20%"는 퍼센트·확률 수치에 곱합니다(지속 시간은 그대로).
- **밸런스 원칙**: 캠페인은 기술 나무 없이도 ★3이 가능해야 합니다. 기술 나무는 무한 모드와 편한 플레이를 위한 것입니다.

### 13.2 전투 조작

| 입력 | 동작 |
|---|---|
| 탑 목록에서 탑 누르기 → 맵의 칸 누르기 | 탑 짓기. 고른 동안 칸 위에 탑 미리보기(지을 수 있으면 초록, 없으면 빨강)·사거리·생길 공명이 보임. `Shift`를 누른 채 놓으면 이어서 짓기, `Esc`·오른쪽 클릭·같은 탑 다시 누르기로 취소 (2026-11-10 개정: 예전엔 빈 칸을 먼저 누르는 건설 메뉴) |
| 탑 목록에서 맵으로 끌어다 놓기 | 탑 짓기 (손가락은 탑이 손가락 바로 위 칸에 보임, 목록이나 맵 밖에서 떼면 취소) |
| 숫자 키 `1`~`9`, `0` → 방향키 → `Enter` | 키보드로 탑 고르고 놓기 |
| 탑 없이 빈 칸 누르기 | "탑 목록에서 탑을 골라 놓으세요" 안내 |
| 탑 누르기 | 탑 정보 (능력치, 공명 연결, 강화/분기, 표적, 판매) |
| 적 누르기(휴대폰은 길게) | 적 정보 (체력, 특성, 저항) |
| 영웅 누르기 → 땅 누르기 | 영웅 이동 |
| `Space` | 웨이브 호출 |
| `Q` | 영웅 기술 |
| `H` | 영웅 선택 |
| `U` / `S` | 선택한 탑 강화 / 판매 |
| `F` | 배속 바꾸기 |
| `P` / `Esc` | 일시정지 / 취소 |

### 13.3 정보 표시 원칙

1. 탑을 고르거나 지을 때 **사거리 원**을 보여 줍니다.
2. 건설 미리보기에서 **생길 공명 연결 선과 효과 이름**을 보여 줍니다.
3. 적 머리 위에 체력 막대, 보호막은 다른 색으로 겹쳐 표시합니다. 특성은 적 정보에서 아이콘으로.
4. 웨이브 호출 버튼에 **다음 웨이브 적 구성**(아이콘과 수)과 조기 호출 보너스를 표시합니다.
5. 색만으로 정보를 전달하지 않습니다. 원소에는 모양, 상태에는 아이콘을 함께 씁니다.

### 13.4 휴대폰

- 전투 화면은 **가로 화면**으로 합니다. 세로로 들면 "가로로 돌려 주세요" 안내를 띄웁니다(메뉴 화면은 세로도 지원).
- 정보는 맵 위가 아닌 **양옆 띠**에 두어 맵이 화면 높이를 모두 씁니다. 844×390 화면에서 1칸 ≈ 40px.
- 버튼은 최소 40×40px. 건설·판매는 두 번 눌러 확정합니다.

## 14. 아트 방향

- **스타일**: 굵은 외곽선과 부드러운 그라데이션의 2D 벡터 그림, 위에서 비스듬히 내려다본 시점. 코드로 그린 SVG를 캔버스에 그립니다(외부 그림 파일 없음).
- **색**: 지역마다 바탕 색조(들판=연두·노랑, 고개=하양·하늘, 협곡=주황·적갈, 해안=청록·남색, 대종=회보라·금). 아군(탑·영웅)은 따뜻하고 선명하게, 적은 잿빛 바탕에 원소 색 포인트.
- **읽힘**: 작은 화면에서도 실루엣만으로 탑 종류와 적 종류를 구별할 수 있어야 합니다. 탑 단계가 오를수록 커지고 장식이 늘어납니다.
- **움직임**: 적은 걸음에 맞춰 통통 튀고, 탑은 공격할 때 반동, 투사체는 원소별로 다른 궤적과 잔상, 처치 시 원소별 파편.
- **검수**: 모든 그림을 하나씩 개별 이미지로 찍어 직접 확인합니다([QUALITY.md](QUALITY.md) §4).

## 15. 사운드 방향

- WebAudio로 실시간 합성(외부 파일 없음).
- **음악**: 지역마다 하나의 테마(들판=밝은 목관풍, 고개=맑은 종소리, 협곡=타악기, 해안=넓은 화음, 대종=종소리와 낮은 저음), 보스 테마, 타이틀·지도 테마.
- **효과음**: 원소별 공격음(불=파삭, 얼음=쨍, 폭풍=지직, 대지=쿵, 빛=맑은 울림, 어둠=낮은 웅웅), 건설·강화·판매, 웨이브 시작, 불꽃 꺼짐, 승리·패배.
- 같은 효과음이 한꺼번에 많이 나면 수를 제한해 귀가 아프지 않게 합니다.

## 16. 접근성과 편의

- 원소·상태는 색 + 모양/아이콘.
- 큰 글씨 설정.
- 화면 흔들림 끄기.
- 키보드만으로 전투 가능: 방향키로 칸 커서를 옮기고 `Enter`로 고르기, `1`~`9`로 탑, `U` 강화, `1`·`2` 분기, `S` 판매, `Space` 호출, `Q`·`H` 영웅. 확인 창은 `Enter`(확정)·`Esc`(닫기).
- 일시정지 중에도 건설 가능 → 반응 속도에 자신 없는 사람도 즐길 수 있게.
- 진행 상황 자동 저장, 판 도중 나가도 이어하기.
