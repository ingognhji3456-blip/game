# 탑 그림 검수 — 🪨 대지 · ✨ 빛 · 🌑 어둠 (towers-b.js)

- 대상: 바위 병영·대지 망치·수정 광산·햇살 렌즈·성소·광휘 탑·저주 첨탑·공허 구체·그림자 덫 9종 × 5단계(Lv1·Lv2·Lv3·Lv4 A·Lv4 B) × 3자세(`idle`·`aim`·`fire`) = **135장**
- 기준: `docs/design/animation.md` §2.1(탑 자세)·§2.6(건물다운 탑과 그림자)·§3(개연성 점검표), `docs/design/towers.md`(외형·분기)
- 검수 방법: `node tools/art-review.js towers <id>` → `docs/reports/art/towers/<id>.png`. 9장(각 15칸, 큰 그림 + 게임 크기·반전)을 한 장씩 열어 보고, 사람·손·도구는 작업용 확대 캡처(틀 좌표 일부를 560px로)로 따로 확인. 고친 뒤 다시 찍어 확인. 판정 기준은 "한눈에 이상하지 않다".
- 실제 게임 화면(`index.html?screen=game&map=4-2`)에 9종 × 3단계를 지어 렌더러 그림자와 함께 캡처: 받침이 칸 하나에 들어맞고, 빛 방향이 맞으며, 다른 탑 사이에서 튀지 않음.
- 엄격 모드: 135장 모두 오류·NaN 없이 그려지고, 같은 탑·단계의 세 자세가 모두 서로 다름(작업용 점검 스크립트). `node tests/run.js data` 11개 통과.

## 다시 그린 방식 (공통)

- **건물처럼**: 고정 난수로 돌 하나하나를 줄눈과 함께 쌓는 `masonry`(막돌·다듬은 돌, 원기둥이면 줄이 휘고 왼쪽이 밝음, 돌 윗변에 빛), 나무 결과 위쪽 빛이 있는 각목 `beam`, 못 박힌 널빤지 `planks`, 기와·초가·널·돌판 지붕면 `roofPlane`, 안쪽 불빛이 있는 창 `win`(창턱 아래 짙은 그늘), 리벳·이끼 덩이. 같은 탑의 세 자세는 같은 난수라 벽이 흔들리지 않음.
- **받침(기초)**: 공용 `plat`와 크기·높이·단계 표시가 같은 `base`를 파일 안에 새로 둠 — Lv1 막돌 테 + 못 박힌 널 마루, Lv2 다듬은 돌 + 판석 윗면, Lv3 + 리벳 박힌 금속 테·원소 보석, Lv4 2단(아래 큰 막돌, 위 다듬은 돌 + 원소 띠·보석). 맨 아랫줄은 땅에 닿아 어둡게.
- **빛·그늘**: 빛은 왼쪽 위. 처마·들보·흉벽 아래 형태 그림자, 건물이 받침에 닿는 곳에 접지 그늘(`ao`). 바닥에 떨어지는 그림자는 그리지 않음(렌더러 몫).
- **사람**: `fig` — 엉덩이·몸통 기울기에서 어깨·목·머리를 계산하고, 두 마디 IK로 팔꿈치·무릎을 구해 관절이 이어진 팔다리, 쥔 주먹, 장화. 그리는 순서(뒷다리·뒷팔 → 몸 → 손에 든 도구 → 뒷손 → 앞팔)로 도구가 늘 손에 쥐어짐. 몸통·옷은 왼쪽이 밝고 주름은 빛 반대쪽. 골렘 병사는 `golemFig`(같은 관절 규칙).
- **같은 인물·장치**: 광산 = 수염 난 광부(천 모자 → 가죽 투구·촛불 → 쇠 투구·이마 등·장갑·금테 곡괭이, 4A 권양기, 4B 앞치마·확대경), 성소 = 베일 쓴 사제(금테 → 금 머리띠 → 대사제 관·지팡이 / 초록 띠 치유 사제), 병영 = 이끼 돌 골렘 문지기, 망치 = 같은 물레방아 공이 틀, 저주 = 같은 "지켜보는 눈", 공허 = 같은 돌손, 덫 = 같은 그림자 사냥꾼.
- `muzzle`은 `aim`·`fire`의 렌즈·구슬·눈·손끝(덫이 손을 떠나는 곳)·내리찍는 점에 맞춤(저주 첨탑 Lv2·Lv3·4A는 눈 위치를 옮겨 값도 바꿈).

## 남은 점

- 받침 `base`가 공용 `plat`보다 자세함(돌 하나하나). 불·얼음·폭풍 탑(towers-a.js)이 `plat`를 계속 쓰면 받침 결이 다를 수 있음 → 한쪽으로 맞추려면 `base`·`masonry`를 `towers.js`(공용)로 옮기는 것을 권함.
- 돌쌓기 때문에 SVG 문자열이 커짐(장당 약 30~105KB, 가장 큰 것은 대성당). 스프라이트는 한 번 래스터화해 두므로 실행 중 부담은 없지만 첫 준비 시간이 조금 늘 수 있음.
- 게임 크기(약 32px)에서는 돌 줄눈·나무 결이 질감 정도로만 보임. 자세 차이는 깃발·문·곡괭이·망치·빛 번짐처럼 큰 동작으로 읽히게 함.
