# 영웅·유닛 그림 검수 (동작 개정)

- 대상 파일: `js/art/heroes.js` (영웅 6명 × 9자세, 유닛 5종 × 5자세, 초상화는 그대로 두고 대조)
- 검수 이미지: `docs/reports/art/heroes/<id>.png`, `docs/reports/art/units/<id>.png`, `docs/reports/art/portraits/<id>.png` — 모두 한 장씩 열어 `docs/design/animation.md` §3 점검표로 판정. 게임 화면(맵 5-1, 영웅 6명 각각)도 캡처해 크기·기준점·실루엣을 확인함.
- 그리는 방식: 인물마다 자세 표 하나(몸 위치·기울기·숨, 두 발, 두 손, 무기 각도)를 두고 같은 함수가 읽음. 팔·다리는 두 마디 역운동학(ik), 무기는 손이 쥐는 점에서 계산하고 주먹을 자루 위에 덮어 그림. 빛은 왼쪽 위(면마다 오른쪽 아래 그늘, 가까운 팔이 몸통에 그늘), 바닥 그림자는 그리지 않음.
- 판정: **통과** = 이상한 데가 눈에 띄지 않음 / **고침** = 검수 중 고친 내용.

## 남은 점 · 메모
