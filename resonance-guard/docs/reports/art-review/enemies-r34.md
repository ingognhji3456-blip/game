# 적 그림 검수 — 3·4지역 (js/art/enemies-r34.js)

> 사용자 의견(2026-11-09): "다 붙여서 대충 만든 것 같다. 하나하나씩 그려 달라… 공격 모션, 공격 전 대기 모션, 휘두르기·던지기… 개연성이 떨어진다."
> 추가 의견: "몬스터들도 다 다시 새로 개편하고, 이동할 때 움직임이며 죽을 때며 다 다르게… 그림자까지 섬세하게."
>
> 기준: `docs/design/animation.md` §2.2(프레임) · §2.5(움직임·죽음) · §2.6(빛·그림자) · §3(개연성 점검표).
> 검수 방법: `node tools/art-review.js enemies <id>` → `docs/reports/art/enemies/<id>.png` 18장을 **한 장씩 열어** 9프레임(큰 그림 + 게임 크기·뒤집기)을 모두 확인. 이상한 곳은 고치고 다시 찍어 재확인.

## 만든 방식 (모든 적 공통)

- 18종 모두 `D.<id> = (fr) => {…}; D.<id>.frames = true;` — 프레임 이름 9개(`walk0~3`, `aim`, `attack`, `die0~2`)를 받습니다.
- 짐승마다 **자세 표**(등뼈 조절점, 엉덩이·어깨 위치, 발·손 목표점, 몸 기울기, 무기 각도)를 두고 같은 그리기 함수가 표를 읽어 그립니다 → 모든 프레임이 같은 몸·색·장비.
- 파일 안 도우미
  - `ik()` 두 마디 관절 계산(엉덩이→무릎→발목, 어깨→팔꿈치→손). 무릎은 앞으로, 팔꿈치는 뒤로 꺾임.
  - `chain()`/`solid()` 마디들을 **외곽선 하나로 합쳐** 칠함 → 관절 이음매에 선이 끊기지 않음(붙여 놓은 느낌 제거). 위팔·허벅지는 굵고 아래팔·정강이는 가늘게.
  - `tube()`+`spline()` 굵기가 변하는 몸(도마뱀 몸통·꼬리, 벌레, 장어, 고래).
  - `human()` 사람꼴 골격(약탈자·투석병·해적·선원·술사), `brute()` 덩치 골격(용암 덩치·산호 거인), `wingD()` 어깨→팔꿈치→손목→끝 날개(깃은 늘 꼬리 쪽으로 끌림), `claw()` 게 집게, `fist()` 쥔 손, `bootD()` 신발.
- 무기는 손에 쥠: 칼·작살·지팡이는 손 좌표에 자루를 두고, 손(주먹)을 자루 **위에** 다시 그려 손가락이 감싼 것처럼 보이게 함. 투석끈은 손에서 나옴.
- 빛(§2.6): 몸통은 왼쪽 위가 밝은 방사형 그라데이션, 팔다리는 위→아래로 어두워짐(접지 쪽이 가장 짙음), 먼 쪽 팔다리는 한 단계 어둡게, 몸통 오른쪽 아래에 형태 그림자 띠. **땅 그림자는 그리지 않음**(렌더러 몫). 발바닥 외곽선은 y=90.
- 움직임 성격(§2.5)은 파일에서 `RG.art._en.MOTION.<id>`로 지정(아래 표마다 적음).

## 3지역 · 붉은 협곡

### 불도마뱀 `cinder_lizard` (소)
- 움직임: `{ gait: 'scuttle', bob: 0.015, tilt: 2, sway: 0.025, deathFx: 'ash', deathTime: 0.7 }`
- walk: 낮게 엎드린 몸, 대각선 다리 짝(앞-가까운+뒤-먼 / 앞-먼+뒤-가까운)이 번갈아 앞으로. 1·3번에 드는 발이 뚜렷이 들림, 꼬리가 위아래로 흔들림, 등 가시 끝에서 불씨.
- aim: 뒷다리로 버티고 몸을 젖혀 앞발 발톱을 펼침, 입을 벌림, 꼬리 말아 올림, 가시가 곤두섬.
- attack: 몸을 쭉 뻗어 물어뜯음(입에서 불씨), 앞발은 앞으로 할퀴고 뒷다리는 밀어냄.
- die0 맞고 머리를 뒤로 젖히며 앞발이 들림 → die1 납작 엎어져 다리가 옆으로 벌어지고 불씨가 식어 색이 바램(눈 X, 연기) → die2 잿빛 껍데기가 마디마디 부서져 재 더미로, 마지막 불씨와 연기.
- 판정: **고침** — 처음 그린 다리가 개처럼 길어 도마뱀답지 않음 → 짧고 옆으로 벌어진 다리로, 몸을 낮춤. 공격 때 머리가 그림 밖으로 나가 몸을 왼쪽으로. die0이 aim과 비슷해 머리를 뒤로 꺾는 자세로 바꿈. 재확인 후 통과.

### 모래 굴착충 `sand_burrower` (중, 굴착)
- 움직임: `{ gait: 'slither', bob: 0.02, tilt: 2, sway: 0.03, deathFx: 'crumble', deathTime: 0.8 }`
- walk: 모래 둔덕에서 몸 앞쪽이 활처럼 솟아 물결침(마디 고리 위상이 뒤로 흐름), 배 쪽 짧은 다리가 번갈아 모래를 긁고 뒤로 모래알이 튐. 큰 턱이 여닫힘.
- aim: 코브라처럼 뒤로 높이 젖혀 턱을 활짝 벌림. attack: 앞으로 내리꽂아 턱을 꽉 닫음 + 모래 튐.
- die0 맞고 몸을 뒤로 꺾음(눈 X) → die1 모래 위로 축 늘어짐 → die2 모래 속으로 가라앉아 마지막 마디와 턱 끝만 둔덕 위로.
- 판정: **고침** — 꼬리 끝(둥근 마구리)이 땅 아래로 비어져 보임 → 땅선에서 잘라(clip) 모래 속으로 들어간 것처럼. 둔덕이 빵처럼 보여 울퉁불퉁한 두 봉우리로. 턱이 오른쪽 끝에서 잘려 몸을 왼쪽으로. die1 아래턱이 땅 밑으로 → 턱 각도 줄임. 재확인 후 통과.

### 용암 덩치 `magma_brute` (대, 죽음 폭발)
- 움직임: `{ gait: 'stomp', bob: 0.035, tilt: 3, sway: 0.01, deathFx: 'crumble', deathTime: 1.0 }`
- walk: 무거운 쿵 걸음 — 다리 하나씩 들림(1·3번), 팔은 다리와 반대로 흔들림. 팔·다리 마디마다 빛나는 용암 금.
- aim: 두 주먹을 머리 위로 모아 들어 올림(몸을 뒤로 젖힘, 불씨). attack: 두 주먹으로 앞 땅을 내리찍음 — 용암 튐·땅 갈라짐·돌 파편.
- die0 금이 하얗게 달아오르며 뒤로 휘청, 가슴 파편이 튐 → die1 무릎 꿇고 고꾸라지며 금에서 용암이 흘러 땅에 고임 → die2 식어 굳은 바위 더미 + 검게 굳은 용암 + 김, 빛 꺼진 머리.
- 판정: **고침** — aim 주먹이 그림 위로 잘림 → 높이 낮춤. die1 용암 줄기가 검은 막대처럼 보임 → 외곽선 없는 빛나는 줄기로. 내리찍기 효과의 검은 삼각형 → 빛나는 방울로. die1 주먹이 땅 밑으로 → 올림. 재확인 후 통과.

### 열풍 독수리 `thermal_vulture` (중, 비행)
- 움직임: `{ gait: 'fly', bob: 0.04, tilt: 4, hover: 0.5, deathFx: 'feathers', deathTime: 0.8 }`
- walk: 날개 위(0) → 내려치며 펼침(1) → 아래(2) → 손목이 먼저 올라가는 올림(3). 날개는 어깨→팔꿈치→손목→끝으로 이어지고, 덮깃(안쪽 짙은 줄)과 불꽃색 바깥 깃이 갈라짐. 다리는 꼬리 밑으로 접음.
- aim: 날개를 높이 들고 몸을 세워 발톱을 앞으로, 부리를 벌림. attack: 머리를 숙여 내리꽂으며 발톱을 쫙 펴 낚아챔(불꽃 줄).
- die0 맞고 날개가 꺾이며 깃털이 흩날림 → die1 곤두박질(뒤집혀 떨어짐) → die2 땅에 날개를 펼친 채 쓰러짐.
- 판정: **고침** — 날개가 작고 어두워 불꽃 깃이 안 읽힘 → 날개 길이·폭을 키우고 끝을 밝은 불꽃색으로. die1·die2 머리가 잘림 → 위치 조정, die2 다리가 땅 밑으로 → 접은 다리. 재확인 후 통과.

### 모래 약탈자 `dune_raider` (중, 질주)
- 움직임: `{ gait: 'walk', bob: 0.05, tilt: 3, deathFx: 'mist', deathTime: 0.9 }`
- walk: 접촉→지나감→접촉→지나감, 팔은 다리와 반대. 앞손이 언월도를 낮게 앞으로 쥠(금빛 코등이·손잡이를 손가락이 감쌈). 두건 꼬리·망토 자락이 날림, 정강이 감개·허리띠 버클.
- aim: 칼을 어깨 뒤로 젖혀 듦(몸을 뒤로 비틂). attack: 앞으로 비스듬히 베어 내림 + 칼자국 호, 뒷발 끝으로 밀기.
- die0 칼을 놓치며 뒤로 휘청(칼이 공중에) → die1 무릎 꿇고 고꾸라짐, 칼은 땅에 → die2 몸은 안개로 흩어지고 두건·옷가지·칼만 남음.
- 판정: **고침** — 걸을 때 칼이 몸 앞에 세워져 몸을 가림 → 낮게 앞으로 겨눈 자세로. 떨어진 칼이 오른쪽 끝에서 잘림 → 안으로. 재확인 후 통과.

### 흑요석 딱정벌레 `obsidian_beetle` (중, 갑옷)
- 움직임: `{ gait: 'crawl', bob: 0.012, tilt: 1.5, sway: 0.01, deathFx: 'shatter', deathTime: 0.8 }`
- walk: 여섯 다리 삼각 걸음(가까운 앞·뒤 + 먼 가운데 / 나머지)이 번갈아. 다리는 넓적다리→정강이→갈고리 발. 깎인 면 반사(왼쪽 위 밝음, 오른쪽 아래 짙음), 껍질 가장자리 밑 불빛.
- aim: 앞을 들어 뿔을 치켜듦, 앞다리 들기, 큰턱 벌림. attack: 뿔로 들이받음(불똥·충격선).
- die0 껍질에 하얗게 빛나는 금 → die1 유리 조각으로 산산이 깨져 날아감(속몸·오그라든 다리) → die2 흑요석 조각 더미와 꺼져 가는 불빛.
- 판정: **고침** — 다리가 직각으로 꺾인 탁자 다리 같았음 → 앞다리는 앞으로, 뒷다리는 뒤로 벌어진 곤충 다리로. 공격 때 머리가 잘려 위치 조정. 재확인 후 통과.

### 협곡 투석병 `canyon_slinger` (중, 원거리)
- 움직임: `{ gait: 'trot', bob: 0.06, tilt: 4, deathFx: 'crumble', deathTime: 0.7 }`
- walk: 머리가 큰 작은 약탈자의 종종걸음. 앞손에서 투석끈 두 가닥과 돌 주머니가 걸음에 따라 흔들림, 허리에 돌 주머니, 두건 꼬리.
- aim: 팔을 머리 위로 들어 투석구를 빙빙 돌림(점선 궤적, 돌이 원 끝에). attack: 팔을 앞으로 채며 끈 하나를 놓아 돌이 날아감(속도선), 뒷발이 들림.
- die0 머리를 맞고 젖혀지며 끈이 늘어지고 돌이 떨어짐 → die1 벌렁 나자빠져 다리가 들림 → die2 큰대자로 누운 채 주머니의 돌이 쏟아짐.
- 판정: **고침** — 걸을 때 투석끈이 바지 색에 묻혀 안 보임 → 짙은 가죽끈·밝은 돌로, 손을 앞으로. 누운 머리 그림이 따로 놀아 살아 있을 때와 같은 머리 그림을 돌려 씀. 재확인 후 통과.

### 👑 용암 벌레왕 `pyre_worm` (보스)

- walk: 용암 웅덩이에서 솟은 상체가 물결치며(마디판 위상이 흐름) 머리가 끄덕임. 판 사이 틈에서 용암 빛, 웅덩이 테두리가 몸 밑동을 덮음.
- aim: 높이 치솟아 턱을 쩍 벌림(용암이 흘러내림). attack: 앞으로 내리꽂으며 터져 나옴 — 용암 분출·돌 파편(잠수 후 솟구침 능력 자세 겸용).

- 판정: **고침** — 웅덩이가 몸에 가려 안 보임 → 앞쪽 용암 테두리 추가. aim·die0 머리가 위로 잘림 → 낮춤. 분출이 왕관 모양 → 튀는 용암 방울로. die1·die2 머리가 오른쪽 끝에서 잘림 → 위치 조정. 재확인 후 통과.

### 바위게 `rock_crab` (중, 갑옷)
- 움직임: `{ gait: 'scuttle', bob: 0.015, tilt: 2.5, sway: 0.02, deathFx: 'crumble', deathTime: 0.8 }`
- walk: 다리 두 무리가 번갈아 종종걸음(무릎이 등껍질보다 높게 꺾이는 게 다리), 눈자루, 등에 따개비·해초.
- aim: 두 집게를 높이 들어 활짝 벌림. attack: 큰 집게를 앞으로 뻗어 탁 집음(충격선).
- die0 등껍질이 금 가며 다리 허우적 → die1 발랑 뒤집혀 다리가 하늘로 → die2 뒤집힌 채 다리를 오므리고 굳음.
- 판정: **고침** — 큰 집게가 그림 밖으로 나가고 망치처럼 보임 → 팔꿈치를 몸 쪽으로, 집게를 위로 세우고 벌림을 키움. 뒤집힌 몸이 그림 아래로 잘림 → 위치 다시 계산, 뒤집힌 껍질에 오른쪽 아래 그림자 덧칠. aim·die0 왼쪽 잘림 수정. 재확인 후 통과.

## 남은 문제·확인할 것

- 비행 적(독수리·해파리·요정·고래)의 `die2`는 땅에 떨어진 모습으로 그렸습니다. 렌더러(`corpses`)가 죽음 연출의 앞 60% 동안 `hover` 높이를 0으로 내리므로 die2 때는 땅에 닿습니다(확인함).
- 바위게가 뒤집힌 프레임(die1·die2)은 껍질을 위아래로 뒤집어 그려서 껍질 무늬의 명암이 거꾸로입니다. 오른쪽 아래 그림자를 덧칠해 크게 어색하지는 않지만 완전한 빛 규칙은 아닙니다.
- 덩치 둘(용암 덩치·산호 거인)은 걸을 때 앞팔이 다리를 많이 가립니다(실루엣 의도). 게임 크기에서도 다리 들림은 보이지만 작습니다.
- 소형(불도마뱀·불꽃 정령·물보라 요정)의 `die2`는 게임 크기에서 아주 작게 보입니다("사라지기 직전" 의도).
- 안개 선원 무기 표기(작살총 ↔ 던지는 작살)는 설계서와 맞출 필요가 있습니다.
- 검수 시점에 `node tests/run.js data`의 엄격 모드 테스트가 다른 파일(`js/art/towers-a.js`의 `coil is not defined`, 다른 작업자가 수정 중)에서 멈춥니다. 같은 엄격 모드로 **적 46종 × 9프레임 = 414장**만 따로 돌려 모두 오류 없이 그려짐을 확인했습니다(이 파일 교체 직후 전체 data 테스트도 11/11 통과).
