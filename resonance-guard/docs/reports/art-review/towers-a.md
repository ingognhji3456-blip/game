# 탑 그림 검수 — 🔥 불 · ❄ 얼음 · ⚡ 폭풍 (`js/art/towers-a.js`)

- 기준: `docs/design/animation.md` §2.1(자세), §2.6(건물다운 탑·빛), §3(개연성 점검표)
- 검수 이미지: `docs/reports/art/towers/<id>.png` (`node tools/art-review.js towers <id>`) — 탑마다 15장(5단계 × idle·aim·fire), 큰 그림 + 게임 크기(32px, 좌우 반전)를 한 장씩 열어 확인. 추가로 게임 화면(`index.html?screen=game&map=2-4`)에 18개를 세워 실제 크기·그림자·동작을 확인.
- 판정: **통과** = 점검표 기준 "이상해 보이는 곳 없음", **고침** = 검수 중 발견해 고친 내용(고친 뒤 다시 찍어 통과).

## 공통으로 새로 만든 것

| 도구 | 내용 |
|---|---|
| `man()` | 사람 한 명: 엉덩이→몸통→목→머리, 어깨→위팔→팔꿈치→아래팔→손(쥔 손/편 손), 골반→허벅지→무릎→정강이→장화. 오른쪽 3/4 시점(가까운 어깨 = 오른팔이 화면 왼쪽). 몸 기울기(예비 동작·뻗기), 모자 7종(두건·투구·가죽모자·고글·털모자·머리띠·대머리), 수염·앞치마·흉갑·망토·화살통·팔 보호대 |
| 자세 표 | 궁수(`ARCHER`)·포수(`GUNNER`)·대장장이(`SMITH`)·종지기·사수 — 자세마다 팔꿈치·손 좌표와 기울기. 같은 함수가 표를 읽어 그리므로 자세가 바뀌어도 같은 인물 |
| 건물 재료 | `stoneWall`(원기둥 벽에 돌 하나하나·줄눈·밝은 윗모서리·색 얼룩·접지 그늘·이끼), `stoneRect`(평평한 벽), `ringWall`(포대 고리 담: 안쪽이 보이고 앞 담이 안의 사람을 가림), `beam`(통나무·들보 나뭇결·나이테), `lash`(밧줄 감개), `planks`(널빤지·나뭇결·못), `tileCone`(기와 줄·처마 물결), `gableHouse`(박공집: 기와 경사면·회벽 박공·처마 밑 그늘), `litWindow`(불 켜진 아치 창·창턱 그늘), `footShade`(받침 위 접지 그늘) |
| 효과 | 활·화살(깃·촉·불씨), 불화살 자국, 포구 섬광, 연기 구름, 불티, 서리 알갱이, 소리 고리, 번개 줄기(갈래), 돌풍 덩이·소용돌이 |

- 빛은 모두 왼쪽 위(원기둥 그라데이션 왼쪽 밝음, 돌 윗모서리 밝은 선), 처마·난간·창턱 아래와 벽 아래는 짙게. 땅 그림자는 그리지 않음(렌더러 몫).
- 모든 선은 줄인 뒤에도 약 1.5 이상(자동 검사: 줄인 뒤 1.4 미만인 선 없음 — 1.4는 반올림 값).
- `muzzle`은 aim 자세의 화살촉·포구·수정 끝·창 머리에 맞춤(4A 투석기는 바구니가 놓이는 꼭대기, 종은 종 가운데).

## 남은 점(알려 둘 것)

- 게임 크기(1칸 32px)에서 사람은 머리 3px 정도라 얼굴·손가락은 보이지 않습니다. 동작은 활·포신·망치·종의 큰 각도 변화와 빛(불화살·섬광·코일 빛)으로 읽힙니다.
- Lv1 지원·장치 탑(축전기 Lv1~3, 번개 막대 Lv2)은 idle과 aim의 차이가 주로 "밝기·회전 흐림"이라 32px에서는 작게 보입니다(그래도 fire의 번쩍임은 분명).
- 받침(`plat`)은 공용 도구(`towers.js`)라 이번에 고치지 않았습니다. 받침의 돌 쌓기를 바꾸면 18종이 함께 바뀝니다.
- `muzzle`은 그림과 맞췄지만, 지금 렌더러는 투사체 출발점으로 `TOWER_MUZZLE`을 쓰지 않습니다(`js/render`에서 찾지 못함).
