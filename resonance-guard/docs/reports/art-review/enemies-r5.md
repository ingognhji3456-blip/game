# 5지역 적 그림 검수 — 깨진 대종 (동작 개정)

- 대상 파일: `js/art/enemies-r5.js` (10종, 모두 `.frames = true`, 9자세 `walk0~3 · aim · attack · die0~2`)
- 검수 그림: `docs/reports/art/enemies/<id>.png` (`node tools/art-review.js enemies <id>`) — 자세마다 큰 그림 + 게임 크기(1칸 32px, 좌우 반전)를 **한 장씩 열어** animation.md §3 점검표로 판정.
- 엄격 모드(`RG.art._strict = true`)로 90장 모두 오류 없이 그려짐, NaN·undefined 없음, 그라데이션 id 중복 없음, 9자세가 서로 모두 다름(직접 확인).

## 다시 그린 방식

- **관절 표**: 적마다 자세 → 골반 위치·몸 기울기·발목(들림·기울기)·손·무기 각도 표를 두고, 같은 그리기 함수가 표를 읽음. 그래서 9자세가 같은 인물·같은 비율·같은 장비로 이어짐.
- **두 마디 팔다리**: 역운동학 도우미(`ik`)로 어깨→팔꿈치→손, 엉덩이→무릎→발목을 이음. 무릎은 앞, 팔꿈치는 뒤·아래로 굽음. 마디는 끝이 둥글고 굵기가 줄어드는 `seg`, 꼬리·목·촉수는 매끈한 띠 `ribbon`.
- **쥔 손**: 무기를 먼저 그리고 그 위에 자루와 직각으로 감싼 주먹(`fist`)을 얹음 → 무기가 손에서 뜨지 않음. 방패는 먼 팔이 뒤 손잡이를 쥠(아래팔은 방패 뒤).
- **발**: 장화 바닥 외곽선이 정확히 y=90. 걷기에서 한 발씩 들고, 밀어 차는 발은 뒤꿈치가 들림.
- **빛(§2.6)**: 빛은 왼쪽 위. 몸통 오른쪽 아래 형태 그림자, 팔이 몸에 드리운 그늘, 장화 바닥 접지 그늘, 옷 주름 명암. 바닥 그림자는 그리지 않음(렌더러 몫).
- **가는 세부선**: 문양·끈·구슬처럼 작은 안쪽 부품은 가는 외곽선(1.3)으로 그려 굵은 외곽선(2.5)에 묻히지 않게 함(처음 그림에서 수도사의 종 끈이 까맣게 묻혀 고침).

### 33 · 회색 군단병 `grey_legionnaire` — 통과
- **생김새**: 얼굴 없는 통투구(가로 눈 틈만 하얗게 빛남, 금 볏, 리벳), 판갑 흉갑(가운데 능선·금 테), 판 치마, 무릎받이·정강이받이·철 장화. 먼 팔에 종 문양 직사각 방패, 가까운 손에 창(손잡이 감개, 금 물미·소켓).
- **walk**: 창을 세워 쥐고 발맞춰 행진. 0 오른발 앞 → 1 지나감(몸 위로, 뒷발 들림) → 2 왼발 앞 → 3 지나감. 창과 방패가 다리와 반대로 조금씩 흔들림.
- **aim**: 몸을 뒤로 젖히고 창을 머리 위로 높이 들어 수평으로 겨눔(창끝 반짝), 방패는 앞으로.
- **attack**: 앞발을 크게 내디디며 몸을 실어 찌르기, 창끝 섬광·잔상 선.
- **죽음**: die0 가슴판에 금이 가며 잿빛 김, 뒤로 휘청하며 창이 손에서 기울어짐 → die1 무릎 꿇고 방패가 앞으로 넘어가고 창은 뒤로 떨어짐, 목 틈으로 김이 빠짐 → die2 속 빈 갑옷이 와르르 무너져 투구가 앞으로 굴러감(눈 틈 꺼짐), 방패·창은 땅에.
- **고친 것**: 외곽선이 너무 굵고 어두워 2.5로 줄임 / 걷기에서 창이 투구 얼굴을 가려 창 손을 뒤로 / 금 볏이 투구 뒤에 숨어 앞으로 그리고 두껍게 / 찌르기 창끝이 그림 밖으로 잘려 자세를 뒤로 / die1 방패가 땅 아래로 내려가 위치 조정.

### 34 · 침묵 수도사 `hush_monk` — 통과
- **생김새**: 뒤로 뾰족하게 늘어진 두건, 어둠 속 하얀 눈, 입가리개 천(주름), 어깨 망토, 목에 큰 염주(가운데 금 구슬), 허리 끈과 매듭. 가까운 손에 추를 흰 천으로 묶은 "소리 없는 종", 먼 손엔 염주. 넓은 소매.
- **walk**: 법복 밑으로 발만 보이는 조용한 종종걸음. 앞으로 내디딘 무릎이 법복 자락을 밀어냄, 종이 팔과 함께 흔들림.
- **aim**: 종을 머리 위로 치켜들고(종 둘레에 고요한 빛 고리) 먼 손 검지를 입가리개에 댐("쉿").
- **attack**: 몸을 숙이며 종을 앞으로 휘둘러 종 입에서 끊긴 점선 고리(침묵의 물결)가 퍼짐, 뒤로 뻗은 손의 염주가 흔들림.
- **죽음**: die0 몸이 꺾이며 종을 놓침 → die1 법복이 속부터 비어 천막처럼 내려앉고 두건에서 재 기둥, 소매에서 재가 쏟아짐 → die2 납작한 빈 법복 더미와 빈 두건, 굴러간 종의 천이 풀려 **처음으로 작은 소리**(금빛 고리), 흩어진 염주.
- **고친 것**: 종 끈·구슬이 굵은 외곽선에 묻혀 까맣게 보임 → 가는 외곽선으로, 종 1.3배 / 종을 발치가 아니라 허리 높이로 / 소매가 막대 같아 넓힘 / aim 종이 위로 잘림, die0 종이 땅 아래, die2 종이 오른쪽으로 잘림 → 위치 조정.

### 39 · 침묵의 비룡 `silent_drake` — 통과
- **생김새**: 회색 비늘 비룡. 금빛 뿔 둘, 하얀 눈, 아래턱이 따로 움직이는 주둥이, 등 가시, 바랜 금빛 배 비늘판(줄눈), 꼬리 끝 금빛 가시, 접은 다리와 발톱. 날개는 팔뼈→손목(금 발톱)→손가락뼈 셋, 그 사이 막(먼 날개는 어둡게).
- **walk(날기)**: 날개 위(0) → 가운데(1) → 아래(2) → 가운데(3), 내려칠 때 몸이 떠오름.
- **aim**: 목을 S자로 젖혀 머리를 들고 입을 벌림(입에 빛), 날개를 높이 펼침, 다리를 앞으로.
- **attack**: 몸을 앞으로 숙여 내리 덮치며 목을 뻗어 물기(이빨), 날개는 뒤로, 발톱은 앞으로, 덮치는 궤적.
- **죽음**: die0 맞고 목이 뒤로 꺾이며 날개 한쪽이 접힘, 비늘 조각 → die1 날개를 접고 머리부터 곤두박질(꼬리가 위로) → die2 땅에 처박혀 옆으로 누움, 날개가 구겨지고 먼지(렌더러가 die2에서 땅에 내려놓으므로 y=90에 맞춤).

### 40 · 울림 포식자 `resonance_eater` — 통과
- **생김새**: 반투명 보랏빛 해파리 갓(속에 은은한 빛, 왼쪽 위 하이라이트, 아래 가장자리 주름), 얼굴판의 하얀 눈, 소리굽쇠(두 갈래) 모양 촉수 넷. 곁의 공명 선(금빛 끊긴 실)이 흐려짐.
- **walk(떠다님)**: 갓이 펴졌다(0) 오므라들며(2) 앞으로 밀고 나감, 촉수는 한 박자 늦게 뒤로 끌림.
- **aim**: 갓을 뒤로 젖혀 아래 입(어둠 + 이빨 고리 + 금빛)을 크게 벌림, 소리굽쇠를 앞으로 세워 빛남, 금빛 실이 빨려 듦.
- **attack**: 앞으로 덮치며 입을 탁 닫음(닫히는 선), 끊긴 실 조각과 금빛 알갱이를 삼킴, 촉수가 앞으로.
- **죽음**: die0 갓이 움푹 꺼지고 촉수가 사방으로 뻗침 → die1 갓이 두 쪽으로 찢어지며 **삼킨 울림이 금빛 음표로** 터져 나옴 → die2 납작한 막과 땅에 떨어진 소리굽쇠, 위로 떠오르는 금빛.
- **고친 것**: 입이 작아 aim이 약해 입·이빨을 키움.

### 👑 보스 5 · 종지기 `bellkeeper` — 통과
- **생김새**: 초상화(`RG.art.portrait('bellkeeper')`)와 같은 인물 — 등에 진 청동 종(꼭지 고리, 오른쪽 금, 짙은 띠, 녹청), V자 가죽끈, 회색 두건과 어두운 안쪽, 종 모양 흰 가면(꼭지·오른쪽 금·하늘빛 눈 틈·아래 회색 추 구슬), 회색 법복과 넓은 소매, 허리띠 금 버클. 손에는 대종을 치던 긴 종메(나무 자루·감개, 청동 테 두른 메머리).
- **walk**: 종메를 지팡이처럼 앞으로 짚으며 엄숙하게 걷기 — 짚은 자리는 몸이 나아가며 뒤로 밀리고(0→2), 3에서 들어 앞으로 옮김. 등의 종이 걸음에 맞춰 흔들림.
- **aim(보호막·순간이동 준비)**: 두 손으로 종메를 앞 위로 치켜듦, 메머리에 결계 고리(점선 안쪽 고리), 등의 종이 빛나고 가면 눈빛이 강해짐.
- **attack(능력·타격)**: 두 손으로 종메를 앞 아래로 내리쳐 종소리 고리가 퍼짐, 뒤에 반투명 잔상과 움직임 선(앞으로 순간이동).
- **죽음(1.2초)**: die0 가면에서 김이 새며 뒤로 휘청, 종메가 기울어짐 → die1 무릎 꿇고 가면 반쪽이 떨어져 **따뜻한 금빛 눈**이 드러남(울림을 되찾은 순간, "미안하다"), 종은 등에서 내려와 뒤에 놓이고 종메는 땅에 → die2 땅에 선 종에 빈 법복과 두건이 기대 걸리고, 깨진 가면 두 쪽과 종메가 앞에, 종이 나직이 울림(금빛 고리).
- **고친 것**: 처음엔 그림이 커서 종·메머리가 잘림 → 0.95배로, 종은 0.8배로 어깨 위에 / 걷기에서 종메가 가면을 가려 걷기에는 먼 손이 앞으로 짚게(두건 뒤로 지나감), aim·attack에서만 두 손으로 몸 앞 / 가면을 키우고 옆모습 비율로 / attack 고리가 잘려 메머리를 안쪽으로 / die1 종이 왼쪽으로 잘려 위치 조정.

### 👑 최종 보스 · 침묵 `the_silence` — 통과
- **생김새**: 땅에 고인 잿빛 안개 밑동에서 솟은 거대한 형체. 해진 끝이 들쭉날쭉한 어깨 망토, 긴 두 마디 팔과 세 갈래 갈고리 손, 얼굴 대신 앞을 향한 깨진 청동 종의 입(속은 텅 빈 어둠, 깊숙이 하얀 눈 둘, 이 빠진 테두리), 몸 곳곳의 빛나는 금, 둘레를 도는 청동 조각, 빨려 드는 여섯 원소 빛.

- **aim(능력 준비·페이즈 전환)**: 몸을 일으켜 두 팔을 활짝 벌리고, 여섯 원소의 실이 종 입으로 빨려 듦, 뒤 빛 무리가 짙어짐.
- **attack(공명 정지)**: 앞으로 덮치며 종 입에서 소리 없는 회색 점선 고리 — 원소의 실이 회색으로 얼어 끊김, 팔을 앞으로 뻗음.
- **죽음(1.2초)**: die0 종 얼굴의 금이 터지며 빛이 새고 몸이 젖혀짐 → die1 몸이 재로 흩어지며 **속에서 여섯 빛이 터져 나옴**, 종 얼굴이 기울어 떨어짐 → die2 땅에 선 깨진 종과 다시 울리는 금빛 고리, 여섯 빛이 떠오름(엔딩 "대종이 다시 울린다"와 이어짐).
