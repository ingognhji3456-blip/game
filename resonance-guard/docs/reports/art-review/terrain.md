  - 전체 시트: `docs/reports/art/terrain/terrain.png` (`node tools/art-review.js terrain`, 1칸 = 32px) — 잘라서 한 장씩 확인

## 무엇이 바뀌었나 (공통)

| 대상 | 이전 | 지금 |
|---|---|---|
| 그리는 방법 | 칸마다 같은 모양을 찍어 붙임 | 칸 종류마다 **거리장**(칸 덩어리 경계까지의 거리)을 만들어 흐리고 잡음을 더한 뒤 등고선으로 뽑음 → 경계가 들쭉날쭉, 칸 이음매 없음. 해시는 `(map.id, c, r)`로 결정적(Math.random 없음) |
| 길 | 같은 폭의 띠 | 길 칸 중심을 잇는 뼈대까지의 거리 → 굽이·갈림길이 저절로 둥글게. 풀 쪽 그늘(접지 그늘) → 진한 가장자리 → 흙 → 닳아 밝은 가운데 → 바퀴 자국 2줄(군데군데 끊김) → 돌멩이·풀 → 왼쪽 위 둑이 드리운 안쪽 그늘. 가장자리에 풀/눈/돌이 비집고 들어옴. 공터로 들어가는 길 끝만 벌어지며 흐려짐 |
| 건설지 | 칸마다 도톰한 둥근 네모 판 | 이어진 건설 칸 = **하나의 낮은 돌 축대**(오른쪽 아래 그림자 → 앞면 → 윗면). 윗면은 크기·모양이 제각각인 판석을 **칸 경계와 상관없이** 깐 보로노이 돌깔기, 돌마다 왼쪽 위 변 밝게·오른쪽 아래 변 어둡게, 금·이끼·눈·모래 얼룩. 칸은 **옅은 모서리 십자 + 가장자리 눈금**으로만 표시. 축대 가장자리에 풀·눈이 덮이고 돌이 굴러 나옴 |
| 공터 | 바둑판 + 점선 격자 | 평평한 빈터(밟힌 풀밭·다진 눈·얼음판·평평한 모래·돌바닥), 얼룩 3겹 + 잔풀·자갈·금, 칸 표시는 네 칸 모서리의 아주 옅은 십자뿐. 공터 안 바위·산호·용암 칸 아래에도 공터 바닥이 이어짐 |
| 물 | 둥근 네모 겹 | 젖은 흙 → 모래 물가 → 거품 → 얕은 물 → 깊은 물 3단, 물가 안쪽 그늘(왼쪽 위)·반사(오른쪽 아래), 물가 따라 도는 잔물결 점선, 수련·얼음 조각·파도, 갈대 |
| 용암 | 둥근 네모 + 판 무늬 | 그을린 땅 → 번지는 빛 → 식은 딱지 테두리(밝은 윗선) → 빛나는 가장자리 → 녹은 몸통, 둑 가까이 많고 가운데엔 드문드문 떠다니는 딱지, 흐름 줄기, 거품. 테두리에서 바깥 바위로 갈라져 뻗은 금(안쪽 끝은 빨갛게) |
| 절벽·성벽 | 납작한 돌 띠 | 바위/기둥이 5칸 이상(가장자리는 3칸) 이어지면 높이 20의 돋운 땅: 오른쪽 아래로 긴 그림자 + 접지 그늘, 남쪽 앞면(아래 반은 더 어둡게, 지역별 결·지층·돌 줄눈), 윗면(왼쪽 위 밝은 테·오른쪽 아래 어두운 테, 얼룩·눈). 1·5지역은 갓돌 쌓은 성벽. 절벽에 둘러싸인 나무 칸은 절벽 위 숲으로(나무를 절벽 높이만큼 올림) |
| 나무·바위·기둥 | 그림자 없음 | 모두 오른쪽 아래로 드리운 그림자(키에 비례) + 밑동 그늘. 수관·바위·솔잎에 형태 그림자(오른쪽 아래 어둡게) 추가 |
| 입구 동굴 | 평평한 반원 | 바위 덩이마다 형태 그림자·하이라이트·지역별 이끼/눈 덮개, 동굴 그림자, 안개 |
| 하늘 입구 | 소용돌이를 그림(렌더러와 겹침) | 소용돌이는 렌더러 몫이라 지움. 바닥은 이웃 지형(물/바위/숲/맨땅)으로 채우고 엷은 빛 웅덩이만 |
| 다리 | 회전한 판자 | 세상 좌표로 그려 빛 방향 유지: 판자마다 색·길이 다름, 난간 위쪽 밝고 아래쪽 어둡게, 기둥 하이라이트, 물 위 그림자 |
| 울림등 광장 | 원판 | 둥근 판석 바닥(고리 줄눈 + 방사 줄눈), 연석 테두리 빛/그늘, 접지 그림자. 길과 이어지지 않은 울림등(공터 한가운데)도 광장만 |

- 성능: 맵 하나 SVG 평균 740KB, 최대 970KB(3-6) — 기준 1.5MB 이하. 만드는 시간 Node에서 평균 0.23초(최대 0.36초), 맵당 한 번만 래스터화. 필터는 용암 번짐 흐림 하나뿐. 같은 맵은 최근 몇 개를 기억해 준비 화면·전투 화면이 다시 만들지 않음.
- 결정성: 같은 맵을 두 번 만들면 그라데이션 id(호출 순서에 따라 붙는 번호)만 다르고 그림은 같음.

## 검수 중 고친 것 (공통)

1. 첫 판(칸마다 판석 하나)은 여전히 바둑판처럼 보임 → 둥근 판석 + 둘레 돌 → 칸마다 큰 판석 한 장 → **축대 하나 + 칸과 무관한 돌깔기 + 옅은 모서리 십자**로 세 번 다시 그림(조정자 검토 의견 반영).
2. 2지역: 건설 축대(회청색 + 눈 얼룩)와 절벽 윗면(눈 + 회청색 얼룩)이 비슷해 구별이 어려움 → 절벽 앞면을 짙게, 윗면 눈이 테두리를 덮지 않게, 그림자를 진하게, 축대의 눈 얼룩을 크게 줄임.
3. 3지역: 절벽(협곡 벽)과 건설 축대가 같은 주황 → 절벽을 짙은 적갈색으로, 판석을 밝게.
4. 1지역: 성벽 윗면이 판석 축대와 같은 밝기 → 성벽 돌을 어둡고 이끼 낀 회녹색으로.
5. 5지역: 공터와 판석이 같은 회보라 → 공터를 어둡게, 판석을 밝게(금빛 줄눈).
6. 바위 3칸만 붙어도 절벽이 되어 공터 안에 납작한 판이 생김(5-3·4-3·2-3) → 5칸 이상(가장자리 3칸)만 절벽, 공터 안 바위는 공터 바닥 위에 그대로.
7. 용암 칸이 반듯한 네모로 보임(3-3) → 경계 잡음을 크게 키우고 식은 딱지·갈라진 금을 바깥 바위로 뻗게, 공터 바닥에 얼룩·자갈·금 추가.
8. 공터 옆을 나란히 지나는 길 가장자리에 칸마다 톱니가 생김(5-6) → 길 끝이 공터로 들어가는 곳만 벌어지게.
9. 처음 만드는 시간이 맵당 3~4초 → 해시를 32비트 정수 연산으로, 먼 곳 잡음 생략, 전역 `Math` 조회 줄임 → 0.2초대.
10. 용량이 1MB를 넘던 맵(5-2·5-5) → 영역 밖 잡음 등고선 제거, 판석 좌표 정수화, 5지역 길가 돌멩이 줄임.

## 지역 풍경 (`regionBanner`)

- 그림은 그대로 두었고, 나무·바위 기호를 같이 쓰므로 형태 그림자가 생김. 다섯 장 모두 렌더링해 확인 → 통과.

## 남은 일 / 메모

- 건설 칸 표시는 일부러 옅게 했습니다(모서리 십자 + 가장자리 눈금). 탑을 놓을 때는 렌더러의 놓기 미리보기가 칸을 보여 주므로 충분하다고 판단했지만, 휴대폰(1칸 22px)에서 더 진하게 원하면 `drawTerrace`의 `tick` 불투명도만 올리면 됩니다.
- 하늘 입구 칸(장애물 칸)은 이웃 지형으로 채워 작은 풀밭/바위밭처럼 보입니다. 표시는 렌더러 소용돌이에 맡김.
- 그라데이션 id는 `RG.art._h.uid()` 순번이라 문자열은 호출 순서마다 조금 다르지만 그림은 같습니다.
