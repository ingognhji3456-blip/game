# 적 그림 검수 — 1·2지역 (enemies-r12.js)

- 대상: 1지역 솔빛 들판 9종 + 2지역 서리 고개 9종 = 18종 × 9프레임(`walk0~3`·`aim`·`attack`·`die0~2`) = **162장**
- 기준: `docs/design/animation.md` §2.2(적 프레임)·§2.5(움직임·죽음)·§2.6(빛)·§3(개연성 점검표)
- 검수 방법: `node tools/art-review.js enemies <id>` → `docs/reports/art/enemies/<id>.png`. 18장 모두 큰 그림·게임 크기·뒤집기를 한 장씩 열어 보고, 고친 뒤 다시 찍어 확인. 판정 기준은 "한눈에 이상하지 않다".
- 엄격 모드: 162장 모두 오류·NaN 없이 그려지고, 같은 적의 9프레임이 모두 서로 다름(작업용 점검 스크립트). `node tests/run.js data` 11개 통과.

## 다시 그린 방식 (공통)

- **자세 표**: 적마다 프레임 → 몸 기울기·이동, 목·머리 각, 입 벌림, 발 목표점(땅 위 x·들림), 손 목표점과 무기 각도를 표로 두고 같은 그리기 함수가 읽음. 그래서 9프레임이 같은 인물로 보이고 동작이 이어짐.
- **관절로 이은 팔다리**: 어깨·엉덩이(몸 좌표계에서 함께 움직임) → 무릎·팔꿈치(두 마디 IK) → 발목·손목. 굵기가 줄어드는 캡슐을 외곽선 먼저·면은 위에 그려 이음매 없이 붙임(`blob`, `fuse`). 네발짐승 뒷다리는 무릎(앞)·뒤꿈치(뒤) 세 마디.
- **쥔 무기**: 무기는 손 좌표에서 돌려 그리고 그 위에 주먹(장갑·건틀릿)을 덮어 손가락이 자루를 감싼 모양. 낫·칼·창·지팡이·방패 모두 손에서 떨어지지 않음(죽을 때 떨어뜨리는 장면만 따로).
- **빛(왼쪽 위)**: 몸이 기울거나 뒤집혀도 그라데이션 중심을 되돌려 늘 왼쪽 위가 밝음(`lit`). 몸통에는 모양 안쪽에만 오른쪽 아래 그늘과 왼쪽 위 반사광(`form`), 다리는 아래로 갈수록 어두운 접지 그늘(`legG`). 땅 그림자는 그리지 않음(렌더러 몫).
- **걷기 4장**: 0 오른발(가까운 발) 앞·닿음 → 1 지나감(몸 위) → 2 왼발 앞 → 3 지나감. 네발짐승은 대각선 짝, 새는 날개 위→가운데(펼침)→아래→가운데(접음).
- **움직임 성격**: 파일에서 `RG.art._en.MOTION.<id>`로 18종 모두 지정(아래 표의 "움직임").

- **비행 적의 죽음 높이**: 까마귀 die2·눈 요정 die2는 땅(y≈90)에 떨어진 모습으로 그렸습니다. 렌더러가 죽은 비행 적도 `hover`만큼 띄우면 공중에 누운 것처럼 보이니, 죽음 연출 중에는 띄우기를 서서히 0으로 내려 주어야 합니다.
- **MOTION과 프레임의 겹침**: 걷기 프레임 안에도 1~2.5 정도의 위아래 움직임이 있습니다. 렌더러의 `bob`·`hop`을 더하면 조금 커질 수 있어 값은 작게 잡았습니다(포자 새끼 hop .1). 실제 게임 화면에서 한 번 더 봐야 합니다.
- **게임 크기(16~22px)**: 작은 적(쥐·포자 새끼·눈덩이)은 세부가 거의 안 보이고 실루엣·자세 차이로만 읽힙니다. 자세 차이(덮치기, 웅크림, 뒤집힘)는 크게 줬지만 실제 화면 캡처로 다시 확인이 필요합니다.
- 방패병은 이전 그림처럼 방패를 가까운 팔(앞)에 들고 창을 먼 팔에 둡니다(좌우 반전돼도 어색하지 않게 문장·글자 없음).
