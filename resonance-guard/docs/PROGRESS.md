## 다음에 손댈 만한 것

- 탐색 봇은 시드에 따라 결과가 크게 흔들림(같은 맵이 승↔패). 봇 실력이 밸런스 측정의 한계 — 사람이 직접 해 본 소감으로 `hpMult`를 다듬는 것이 가장 정확합니다.
- 4·5지역 보스 맵(4-6 ×0.5, 5-5 ×0.52, 5-6 ×0.52)은 봇 기준으로 체력을 많이 낮췄습니다. 봇은 분기 강화·공명을 사람보다 못 쓰므로, 사람에게는 쉬울 수 있습니다 — 플레이 소감으로 올리는 것을 권합니다.
- 탐색 봇이 감속·밀치기·저주 같은 보조 효과를 잘 평가하지 못해, 겨울 종·바람 포탑·축전기·대지 망치·광휘 탑·저주 첨탑·공허 구체·그림자 덫은 "최적 해법"에 3맵 미만 등장(QUALITY 기준 미달, 보고서에 기록). 그리디 봇 피해 비중은 궁수탑 32%(기준 30%).
- 영웅 피해 비중(그리디 봇 전체) 15%.

## 알려진 문제·메모

- 게임 크기(한 칸 약 32px)에서 사람 머리는 3px쯤이라 탑 일꾼의 동작은 활·포신·망치 같은 큰 모양으로만 읽힘. 발전기 Lv1~3·피뢰침 Lv2는 대기↔조준 차이가 약함(발사 섬광은 분명).
- 적이 60마리를 넘으면 성능을 위해 적의 드리운 그림자·기울임을 생략함(`js/render/renderer.js` `manyEnemies`).
- 그림 함수가 SVG 안 그라데이션 id를 호출 순서로 매겨, 같은 그림도 SVG 글자는 호출마다 다름(그림은 같음).

- 그리디 봇은 길 만들기 맵에서 서툴러 결과가 흔들림(봇 한계, 게임 문제 아님).
- 탐색 봇 개선 기록: 은신 적이 있으면 성소 먼저(최대 1~2개), 갑옷 상성, "소수 정예" 스타일, 탑 하나를 Lv4까지 키우는 변이, 보스에게 준 피해를 점수에, 여러 시드 재시도.
