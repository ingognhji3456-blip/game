## 4. 그림 검수 (하나씩 직접 확인)

모든 그림을 **개별 이미지로 하나씩** 찍어서 직접 봅니다. 기준은 "눈에 띄게 이상하지 않을 것".

| 대상 | 개수 | 찍는 크기 |
|---|---|---|
| 탑 (18종 × Lv1·2·3·4A·4B) | 90 | 원본 크기 + 실제 게임 크기(32px) |
| 울림등 (빛 단계 3가지) | 3 | 〃 |
| 적 (40종 × 걷기 2프레임) | 80 | 원본 + 실제 크기 |
| 보스 (6종 × 2프레임) | 12 | 〃 |
| 영웅 (6명 × 자세 4) | 24 | 〃 |
| 초상화 (영웅 6 × 표정 3 + 조연 3) | 21 | 원본 |
| 유닛 (병사·벽·드론) | 10 | 〃 |
| 맵 바탕 (35개) | 35 | 실제 화면 크기 |
| 지역 풍경 (5) | 5 | 원본 |
| 아이콘 (전부) | 전부 | 원본 + 24px |

**확인 항목** (그림마다):
1. 형태가 깨지지 않았는가(겹침 오류, 잘림, 엉뚱한 위치의 조각, 빈 칸).
2. 설계서의 외형 설명과 맞는가(무기, 색, 특징).
3. 작은 크기에서 실루엣이 다른 것과 구별되는가.
4. 기준점이 맞는가(탑 바닥, 적 발 위치) — 게임 화면에 놓았을 때 떠 있거나 파묻히지 않는가.
5. 좌우 반전했을 때 어색하지 않은가(적·영웅).
6. 같은 탑의 단계가 오를수록 확실히 더 멋있어지는가. 4A와 4B가 서로 다르게 생겼는가.

검수 결과는 `docs/reports/ART-REVIEW.md`에 그림마다 "통과 / 고침(무엇을)"으로 기록합니다.
고친 그림은 다시 찍어서 다시 봅니다.
