## 1. 이야기 (6막)

대종이 다시 울리자 구름 위에서 대답하는 종소리 — 하늘의 쌍둥이 **별종**. 땅에서 쫓겨난 안개가 하늘로 올라가 별빛을 갉아먹고, 별종이 멈추면 밤하늘이 꺼집니다. 6-1~6-6에서 새 영웅 여섯이 차례로 합류하고, 꼭대기에서 **그믐달 군주**를 막으면 두 종이 함께 울립니다(엔딩 2). 장면 id: `s6_1`~`s6_6`, `ending2` ([story.md](story.md)).

## 2. 지형 장치

### 2.1 별다리 (`B` / `b`)
- 두 무리가 **번갈아** 놓입니다. 판 시작은 `B` 열림·`b` 닫힘, `bridges.period`초(기본 14초)마다 바뀜.
- 닫힌 다리 칸은 길이 아님(흐름장에서 막힘) → 적은 열린 다리로 돌아감. **닫히는 다리 위(또는 그 칸으로 가던) 적은 되돌아가지 않고 그대로 건너감**: 다리를 벗어날 때까지 닫히기 전 흐름장을 따름(`e.cross`).
- 다리에는 탑을 지을 수 없음. 공터에 지을 때 **다른 다리 상태에서도** 입구→울림등 길이 남는지 검사("별다리가 바뀌면 길이 막혀서 지을 수 없습니다").
- 맵을 해석할 때 두 상태 모두 길이 있어야 함(아니면 오류).
- 영웅·병사: 닫힌 다리는 걷지 못함. 닫힐 때 위에 서 있던 유닛은 가까운 걸을 수 있는 칸으로 옮겨짐.
- 화면: 열린 다리 = 금빛 별빛 판자, 닫힌 다리 = 옅은 점선 윤곽. **닫히기 3초 전부터 깜박이고 다리 위에 "닫힘 3·2·1"/"열림 3·2·1"**. 바뀔 때 맑은 종소리. 준비 화면 미리보기(바탕 그림)에는 두 무리 모두 옅은 점선.

### 2.2 별빛 건설지 (`*`)
- 일반 건설지와 같고, 여기 지은 탑은 **사거리 +15%** (`rules.starRange`).
- 화면: 비어 있을 때 칸 가운데 금빛 별이 은은하게 반짝임.

## 3. 새 적 8종 + 보스

| 적 | 핵심 | 특성 |
|---|---|---|
| 별가루 나방 `stardust_moth` | 빠른 비행 떼, 얼음 약점 | 비행 |
| 구름 양 `cloud_sheep` | 체력 높은 정예, **범위 피해 절반**, 폭풍 약점 | 푹신 |
| 혜성 기사 `comet_knight` | 갑옷 40% + 처음 맞으면 돌진, 불 저항 | 갑옷·질주 |
| 성운 해파리 `nebula_jelly` | 비행, 죽으면 작은 해파리 셋(20%) | 비행·분열 |
| 그림자 별지기 `umbral_stargazer` | 은신 + 영웅·병사 원거리 공격(3칸) | 은신·원거리 |
| 일식 사제 `eclipse_priest` | 주변 치유(6%/5초) + 보호막(15%/7초) | 치유사·보호막 부여 |
| 유성 골렘 `meteor_golem` | 큰 정예, 죽을 때 폭발(병사·영웅 150), 불 면역·얼음 약점 | 갑옷·죽음 폭발 |
| 위상 망령 `phase_wraith` | **4초마다 0.6초 일렁인 뒤 길을 따라 2칸 앞으로 순간이동**(붙잡혀 있어도 풀림) | 위상 이동 |

- **푹신**: `o2.area`로 들어오는 피해(폭발·파동·장판·튐)를 ×0.5.
- **위상 이동**: 일렁이는 동안 화면에서 깜박이며 흔들림(경고), 이동할 때 사라진 자리·나타난 자리에 보랏빛 효과.

### 그믐달 군주 `gloom_monarch` (보스, 체력 52000 × 맵 배율)
1. **별 가리기** — 12초마다(첫 6초) 경고 원 1.5초 → 원(반경 2.6칸) 안 탑의 사거리 −40%, 5초. 가려진 탑 위에 어두운 초승달 표시.
2. **70%** — 별가루 나방 4마리.
3. **35%** — 길을 따라 3칸 순간이동 + 그때까지 **가장 많이 맞은 원소에 면역**(맞은 양을 원소별로 기록) + 위상 망령 2마리.
