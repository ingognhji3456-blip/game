# 맵 설계서 (지역 5곳 · 맵 30개 · 무한 맵 5개)

> 상위 기준: [DESIGN.md](../DESIGN.md) §4(맵과 길), §10(웨이브), §11(별·공명 과제·모드·해금)
> 실제 격자·웨이브·과제·도전 규칙은 `js/data/maps.js`. 맵 미리보기 그림은 검수 도구가 `docs/reports/art/terrain/`에 생성합니다.

## 설계 원칙

1. **맵마다 질문 하나.** 모든 맵은 플레이어에게 묻는 질문이 하나 있습니다("두 갈래를 어떻게 나눠 막을까?", "숨은 적을 어떻게 볼까?"). 아래 표의 "핵심 질문" 칸에 적습니다.
2. **새 것은 하나씩.** 한 맵에서 새로 나오는 것(탑·적·지형 규칙)은 최대 셋, 그중 "주인공"은 하나입니다.
3. **좋은 자리와 그저 그런 자리.** 길 굽이(여러 방향에서 사거리가 닿는 칸)와 탑 정원(3×3 이상 건설지)을 일부러 만들어, 배치 실력이 드러나게 합니다.
4. **공명 공간.** 모든 맵에는 최소 한 곳 이상 탑 4개 이상을 붙여 지을 수 있는 건설지 덩어리가 있습니다.
5. **길이와 난도.** 적이 걷는 길의 길이는 첫 맵이 가장 길고(여유), 뒤로 갈수록 짧아지거나 갈래가 늘어납니다. 길 만들기 맵은 "최대로 늘렸을 때"와 "아무것도 안 했을 때"의 길이 차이가 2배 이상이어야 합니다.
6. **비행 경로가 보인다.** 하늘 입구가 있는 맵은 준비 단계에서 비행 경로를 점선으로 보여 줍니다.
7. **크기는 16×9로 통일**합니다(휴대폰 가로 화면에서 1칸 40px 확보).

## 맵 목록

각 맵의 웨이브 수·시작 골드는 데이터에서 자동으로 표에 들어갑니다.

- **적 체력**(`hpMult`): 그 맵에 나오는 모든 적(보스 포함)의 체력 배율입니다. 웨이브 구성은 설계대로 두고, 탐색 봇이 기술 나무 없이 ★3을 낼 수 있는 값으로 맞춥니다(`tools/balance.js --search`).
- **초반 몸풀기**(`ramp`): 정예 적만 나오는 5지역은 웨이브 1~3의 적 체력을 60%/75%/90%로 낮춰, 새 지역의 첫 판이 첫 웨이브에서 무너지지 않게 합니다.
- **비행 경로**: 비행 적은 입구(또는 하늘 입구 `A`)에서 등불까지 곧게 날아옵니다. 나선·고리 길처럼 등불이 가운데 있는 맵은 하늘 입구를 멀리 두어 **평균 비행 거리 8칸 이상**을 지킵니다(데이터 테스트로 검사).

## 공명 과제 종류 (엔진이 구현하는 목록)

과제는 판 도중 **어느 순간이라도** 조건을 만족하고, 그 판을 클리어하면 달성됩니다(3-6의 "모두 지은 채 승리"는 승리 순간 기준).

| type | 뜻 |
|---|---|
| `links` | 공명 연결 N개 이상 동시에 |
| `distinct` | 서로 다른 공명 효과 N가지 이상 동시에 |
| `effects` | 이 효과들(id 목록)을 모두 동시에 |
| `stack` | 한 탑에 공명 효과 N개 이상 |
| `amp` | 지정한 지원 탑 하나가 공명 증폭 N개 이상 |
| `elementEffects` | 지정 원소가 낀 서로 다른 공명 효과 N가지 이상 동시에 |
| `pureAll` | 여섯 원소 모두에서 순수 공명 |
| `allElements` | 승리 순간 여섯 원소 탑이 모두 있음 |

## 도전 규칙 종류 (엔진이 구현하는 목록)

도전에서는 항상 **기술 나무 효과가 없고**, 그 시점까지 해금된 탑을 모두 쓸 수 있습니다.

| id | 뜻 |
|---|---|
| `maxTowers` | 탑 최대 N개 |
| `noHero` | 영웅 없이 |
| `lives` | 시작 불꽃 N개 |
| `noOpenBuild` | 공터 건설 금지 |
| `maxLevel` | 강화 최대 단계 N (3이면 분기 금지) |
| `allowElements` | 이 원소 탑만 |
| `banElements` | 이 원소 탑 금지 |
| `banTowers` | 이 탑 금지 |
| `noBlock` | 병영 금지 + 근접 영웅 금지 |
| `noSell` | 판매 금지 |
| `countdown` | 다음 웨이브 카운트다운 N초 |
| `noSupport` | 지원 탑 금지 |
| `noAdjacent` | 탑끼리 이웃해 지을 수 없음 |
