### 2.2 영웅 성장 (판 밖)

- **인연 레벨 1~10**: 그 영웅을 데리고 판을 끝내면 인연 경험치(승리 3 + 새 별마다 2, 패배 1). 레벨마다 **재능 점수 1**.
- **재능 나무** (영웅마다 3갈래 × 3칸 = 9칸, 앞 칸을 찍어야 다음 칸). 언제든 무료 초기화.
  - 1·2칸은 공용 틀(공격 갈래: 공격력 +10% → 공격 속도 +10%, 생존 갈래: 체력 +15% → 받는 피해 −10%, 기술 갈래: 재사용 −10% → 기술 위력 +15%).
  - **3칸은 영웅마다 고유**(공격·기술 갈래 끝 = 24가지): 기술이나 공격이 눈에 띄게 바뀜. 예) 카라 "용암 자국": 내려찍은 자리에 3초 불길 장판 / 시오 "관통 화살": 화살이 적 하나를 뚫고 지나감. 생존 갈래 끝은 공용 "되살아남: 부활 시간 −40%".
- **장비** (장신구 2칸): 18종, 등급 셋(일반·희귀·영웅), 공명석으로 강화(+1~+3). 도전 첫 클리어·무한 기록으로 얻음. 예) "불씨 반지: 공격에 작은 화상", "바람 깃털: 이동 속도 +25%", "등불 조각: 기술을 쓰면 주변 탑 5초 공격 속도 +15%". 같은 원소 영웅이 끼면 수치 +25%.
- 판에 넘기는 값은 판 시작 때 복사(opts.heroGrowth) — 이어하기 재현이 같도록(뽑기 강화와 같은 방식).

## 3. A-1 — 6지역 "별울림 첨탑"

### 3.1 이야기 (6막)
대종이 다시 울리자 구름 위에서 대답하는 종소리가 들립니다. 하늘에 걸린 대종의 쌍둥이 — **별종**. 땅에서 쫓겨난 안개는 사라지지 않고 하늘로 올라가 별종의 울림을 갉아먹고 있었습니다. 별종이 멈추면 밤하늘의 별이 하나씩 꺼집니다. 하루는 형을 따라 수호대에 들어오고, 도한은 하늘 다리의 닻을 벼리고, 바람새 기수 나래가 구름 바다를 건네주고, 숲 정령 토리와 별지기 별이가 첨탑으로 가는 길을 엽니다. 꼭대기 별종의 방에서 기다리는 것은 별빛을 삼킨 **그믐달 군주** — 그리고 침묵에서 돌아와 별종을 지키던 옛 종지기 무진입니다. 끝에서 두 종이 함께 울리고, 하늘과 땅의 울림이 이어집니다(엔딩 2).

### 3.2 지형 장치
- **별다리** (`B` / `b` 두 무리): 일정한 주기(예: 열림 14초·닫힘 14초)로 B 무리와 b 무리가 번갈아 놓입니다. 닫힌 다리는 길이 아니어서 적이 다른 길로 돌아갑니다(흐름장 다시 계산). 다리 위에 있던 적은 그대로 건너감(갇히지 않음). 닫히기 3초 전부터 깜빡임 + 남은 초 표시 — 읽을 수 있는 위협. 탑은 다리에 지을 수 없음.
- **별빛 건설지** (`*`): 여기 지은 탑은 사거리 +15%. 같은 칸 규칙은 일반 건설지와 같음.

## 5. B — 완성도

- **밸런스**: 탐색 봇이 지원·제어·전설 탑, 분기, 영웅 성장을 쓰도록 개선 → 36맵 다시 맞춤. "쓸모없는 탑 없음"(QUALITY) 기준을 32종으로 다시 확인. 새 탑 세기(단일 비교만 한 상태)를 실제 판으로 검증.
- **튜토리얼**: 첫 판(1-1)에서 단계별 안내(손가락 표시: 탑 고르기 → 놓기 → 웨이브 호출 → 강화 → 공명). 건너뛰기·설정에서 다시 보기.
- **접근성**: 색약 모드(원소 색 대비 팔레트 + 무늬), 글자 크기 3단계, 효과 줄이기(번쩍임·흔들림·조각), 고대비 체력 막대, 새 화면(장비·재능)도 키보드만으로.
- **성능**: 6배 느린 휴대폰 30fps 목표(지금 23~25), 무한 40웨이브 메모리 누수 검사.
- **검수**: 장기 실행 10,000판 오류 0, 모든 화면 3크기 캡처 확인, 직접 코드 검토, 품질 보고서 갱신.
