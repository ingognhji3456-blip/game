# 적 설계서 (40종 + 보스 6종)

> 상위 기준: [DESIGN.md](../DESIGN.md) §8(적 공통 규칙·특성 목록)
> 수치 표는 `js/data/enemies.js`에서 자동 생성됩니다(`<!-- AUTO:... -->`).

## 설계 원칙

1. **위협이 하나씩 분명해야 한다.** 적 하나는 "무엇이 위험한지"가 한 가지로 정리되어야 합니다(빠름, 단단함, 숨음, 치유 …). 특성이 둘 이상이면 하나는 보조여야 합니다.
2. **대응법은 최소 둘.** 어떤 적이든 서로 다른 두 가지 이상의 방법으로 막을 수 있어야 하고, **그 적이 처음 나오는 시점에 이미 해금된 수단**이어야 합니다. "이 탑이 없으면 못 깸"은 금지.
3. **처음엔 혼자, 안전하게.** 새 적은 첫 등장 웨이브에서 소수로, 이미 가진 수단으로 막을 수 있게 나옵니다. 그다음 웨이브부터 섞입니다.
4. **실루엣과 색.** 잿빛 바탕 + 지역 원소 색 포인트. 크기 등급(소·중·대·거대)이 실루엣으로 바로 보여야 합니다.
5. **원소 친화는 지역 주제를 따른다.** 서리 고개 적은 얼음 저항·불 약점처럼, 지역이 "이번엔 이 원소를 써 봐"라고 말하게 합니다.

크기 등급: 소(0.5칸) · 중(0.7칸) · 대(0.9칸) · 거대(1.4칸 이상, 보스)

**정예**: 등불 불꽃을 2개 이상 꺼뜨리는 적(크기 "대" 대부분). 데이터의 `elite: true`, 화면에 정예 표시. 황혼 공명·저격대 등의 "정예·보스" 효과 대상입니다. 보스가 등불에 닿으면 즉시 패배합니다.
