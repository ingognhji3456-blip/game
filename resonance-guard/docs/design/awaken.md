# 탑 각성 (Lv5) 설계

> 데이터: `js/data/awaken.js` · 규칙: `js/core/awaken.js` · 판: `js/core/sim.js`(`canAwaken`, `echo`, `onHit.awBurst`) · 그림: `js/render/renderer.js`(`drawAwakenAura`)
> 화면: 탑 정보 창 각성 카드(`js/ui/game.js`), 레이드 화면·도감 미리보기 · 시험: `tests/awaken.test.js`

## 1. 한 줄 요약

**조각 강화 5단계를 채운 탑은 각성**한다. 판 안에서 Lv1 → Lv2 → Lv3 → Lv4(분기) **다음에 Lv5 "각성 강화"**가 생기고,
고른 분기를 그대로 둔 채 **공통 강화 + 탑마다 고유 각성 능력**을 얻는다.

- 사용자 요청(2026-11-13): "각성하면 게임 내 플레이할 때 5번 업그레이드할 수 있게, 최종 업그레이드 그다음에 더 좋은 업그레이드가 되는 거지"
- 정한 것(사용자 선택): 각성 조건 = **조각 5단계** · 각성 효과 = **탑마다 고유 각성 능력**.

## 2. 규칙

- 조건: 탑이 Lv4(분기 고름) + 그 탑의 조각 강화 5단계(`shardLv[탑] = 5`). **도전 모드는 조각을 쓰지 않으므로 각성도 없음.**
  예전 판 이어하기가 다르게 재현되지 않게 `opts.shardStart`가 있는 판만(출정 준비·레이드가 넣음).
- 비용: 분기 비용 × 1.25 (10 단위, 기술 나무 분기 비용 할인 적용). 판매 값은 넣은 골드 그대로 계산.
- 공통 강화(공격 탑): 피해 계열 값 ×1.3(공격력·불바다·가시·불사조·빛줄기·회오리·바위·눈보라·덫·영혼 폭풍·화상), 사거리 ×1.08.
  지원·경제·병영 탑은 공통 강화 없이 고유 능력에 모두 담음.
- 조각 5단계의 다른 효과(공격력 +25%, 한 단계 높게 설치)와 함께 쌓임.
- 키보드: 분기를 고른 탑에서 U = 각성. 탑 정보 창에는 금빛 "✦ 각성" 카드, 조각이 모자라면 "◆n/5 — 마지막 단계를 채우면 각성" 안내.
- 그림: 각성한 탑은 발밑에 원소 빛 고리(천천히 숨쉬듯)와 금빛 테, 머리 위 네 갈래 금별, 가끔 오르는 불티 — 번쩍임 없음(효과 줄이기에도 안전).

## 3. 새 판 기능 (각성용)

- `echo: N` — N번째 공격마다 한 번 더 공격(같은 표적 고르기 규칙). 이벤트 `echo`.
- `onHit.awBurst: { n, radius, pct }` — N번 맞힐 때마다 맞은 적 주변(반경 칸)의 다른 적에게 그 공격 피해의 pct. 이벤트 `pulse`.
- 나머지는 이미 있는 효과(화상·둔화·빙결·저주·저주 번짐·갑옷 파쇄·기절·밀치기·실명·정화·멈춤·가림·처형, 탄 수·연쇄·구역·낙뢰·심판·숨결·빛줄기·불사조·회오리·바위·눈보라·가시·덫·영혼·시간)을 키우거나 더함.

## 4. 탑별 각성 (32종)

| 탑 | 각성 | 고유 능력 |
|---|---|---|
| 불씨 궁수탑 | 불새 화살 | 세 번째 공격마다 한 번 더 쏩니다. 화상이 두 배로 강해집니다. |
| 화염 박격포 | 화산 포격 | 포탄을 한 발 더 쏘고, 불바다가 20% 넓고 1초 더 남습니다. |
| 대장간 | 전설의 대장장이 | 이웃 탑 피해 보너스가 1.5배가 되고, 이웃 탑 공격 속도도 15% 높입니다. |
| 화염 분사기 | 지옥불 | 사거리 +0.4, 화상 두 배. 네 번 맞힐 때마다 불꽃이 터져 주변(0.9칸)에 60% 피해. |
| 서리 결정탑 | 절대 영도 | 두 번 맞힐 때마다 적을 1.2초 얼리고, 둔화가 15%p 강해집니다. 세 번 맞힐 때마다 얼음 파편이 튀어 주변(0.9칸)에 60% 피해. |
| 빙창 쇠뇌 | 쌍빙창 | 두 번째 공격마다 창을 한 번 더 쏘고, 꿰뚫린 적은 세 번에 한 번 얼어붙습니다(0.8초). |
| 겨울 종 | 영겁의 종 | 둔화 70%, 세 번 울릴 때마다 적을 1.5초 얼리고, 종소리가 0.4칸 더 멀리 갑니다. |
| 고드름 구름 | 빙하기 | 고드름이 더 많이 떨어지고(우박 +4·빙하 창 +1), 맞은 적의 갑옷을 깎습니다(10%, 최대 30%). |
| 번개 막대 | 천둥왕 | 연쇄 번개는 4번 더 튀고, 한 방 번개는 맞은 적 주변(1.2칸)에 50% 번개를 터뜨립니다. 맞은 적은 잠깐 기절. |
| 바람 포탑 | 폭풍 대포 | 네 번째 공격마다 한 번 더 쏘고, 비행 적에게 주는 피해가 더 커집니다(+1배). 밀쳐 내기 1.5배. |
| 축전기 | 뇌신 코일 | 이웃 탑 공격 속도 보너스가 1.5배, 이웃 탑이 세 번 공격할 때마다 번개(60)를 더합니다. 방전은 두 배. |
| 뇌운 탑 | 천둥 폭풍 | 번개가 더 떨어지고(천둥신 +1·폭풍 전선 +2), 기절 확률이 20%p 높아집니다. |
| 바위 병영 | 대지의 군대 | 병사가 한 명 더 나오고, 병사 체력·공격력이 1.5배, 다시 나오는 시간이 절반. |
| 대지 망치 | 대지 붕괴 | 내려치는 범위 +0.6칸, 갑옷을 최대 50%까지 깎고, 가시 대지는 피해 두 배·지진 망치는 기절 0.8초. |
| 수정 광산 | 황금 광맥 | 수입이 1.6배. 깊은 광맥은 늘어나는 수입 한도가 두 배, 보석 세공소는 현상금 범위·보너스가 1.5배. |
| 가시 덤불 | 가시 숲 | 가시 덤불을 두 개 더 깔 수 있고, 덤불 피해가 1.5배, 덤불이 더 넓습니다. |
| 햇살 렌즈 | 태양의 창 | 오래 비출수록 커지는 피해가 더 커집니다(집광기는 최대 배율 1.6배, 프리즘은 빛줄기 +1·최대 배율 1.3배). |
| 성소 | 빛의 성역 | 치유가 두 배, 치유 범위 +1칸, 이웃 탑 사거리 보너스 +10%p, 쓰러진 병사가 빨리 다시 나옵니다. |
| 광휘 탑 | 새벽빛 | 세 번째 공격마다 한 번 더 빛을 터뜨리고, 실명 +1.5초, 맞은 적의 보호막을 벗깁니다. |
| 빛의 등대 | 등대의 눈 | 빛줄기가 하나 더 돌고, 비춘 적은 3초 동안 모든 피해를 25% 더 받습니다. |
| 저주 첨탑 | 파멸의 저주 | 저주가 15%p 강해지고, 체력 18% 아래의 적을 처형하며, 저주가 주변으로 번집니다. 세 번째 공격마다 한 번 더 쏩니다. |
| 공허 구체 | 사건의 지평선 | 공허 구역이 15% 넓고 0.5초 더 남으며, 안에 갇힌 적은 더 느려집니다. |
| 그림자 덫 | 그림자 감옥 | 덫을 두 개 더 깔 수 있고, 1초 더 묶으며, 덫 피해가 1.5배. |
| 공포의 종 | 공포의 군주 | 공포가 1초 더 이어지고, 종소리를 들은 적은 받는 피해가 20% 늘어납니다(저주). |
| 불사조 둥지 | 불사조 군단 | 불사조가 한 마리 더 날고, 화상이 1.5배. |
| 눈보라 성채 | 만년 빙하 | 눈보라를 하나 더 부르고, 얼음이 깨질 때 피해가 1.5배. |
| 폭풍의 눈 | 대폭풍 | 회오리가 더 크고(반경 +20%) 2칸 더 멀리 휩쓸며, 휘말린 적을 더 세게 밀어냅니다. |
| 거인의 바위 | 거신의 분노 | 바위를 더 굴리고(산사태 +2·철구 +1), 깔린 적은 0.3초 더 기절합니다. |
| 심판의 첨탑 | 최후의 심판 | 심판이 하나 더 내리고, 현재 체력에 비례한 피해가 1.5배. |
| 영혼 수확자 | 명계의 문 | 모을 수 있는 영혼 +10, 영혼 폭풍 피해 1.5배·범위 +0.5칸. 다섯 번 맞힐 때마다 영혼이 터져 주변(1.1칸)에 70% 피해. |
| 시간의 탑 | 영원의 시계 | 시간을 멈추는 주기가 2번 짧아지고 1초 더 멈춥니다. 세 번째 공격마다 시간을 겹쳐 한 번 더 쏩니다. |
| 흑룡의 둥지 | 멸망의 흑룡 | 숨결이 한 줄기 더, 숨결이 더 굵어지고(+0.2칸), 저주가 10%p 강해집니다. |

## 5. 세기 확인

- 단단한 적(체력 ×30) 앞에서 같은 탑 셋을 Lv4 → Lv5로: 공격 탑 대부분 피해 **×1.6~3배** (조절 대상이 큰 쪽 — 폭풍의 눈·공허 구체·햇살 렌즈·뇌운 탑·화염 박격포는 낮추고,
  서리 결정탑·저주 첨탑·영혼 수확자·시간의 탑은 피해 능력을 더함). 시험 `각성한 공격 탑은 Lv4보다 세다`(×1.15 이상).
- 각성은 조각 200개(5단계)를 모은 탑만 — 후반 보상. 캠페인 밸런스(조각·각성 없는 봇 기준)는 그대로.
- 봇(그리디)도 조각 5단계 탑은 각성시킴(`tests/bots.js`).
